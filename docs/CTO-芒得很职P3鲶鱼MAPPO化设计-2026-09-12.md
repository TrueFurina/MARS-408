## 一、目标与边界

**目标**：AI 面试官的对抗模式（常规/加压/鲶鱼）由规则版升级为 MAPPO 学习策略——何时加压、何时放鲶鱼、何时放松，由策略根据对话上下文自动决策。

**边界**：
- 只换"决策层"：`decide_adversary_mode` 的输出契约（三模式）不变，下游（追问生成/评估）零改动
- 复用 main 分支 `engines/mappo_policy.py` 的 **PPO/GAE/Actor-Critic 训练框架 + warmup_with_rules 机制**（不是复用模型——教学策略与对抗策略状态/动作不同）
- 默认灰度关闭（`use_career_mappo=False`），规则版兜底，与 main 的 `use_mappo_policy` 同模式

## 二、MDP 定义

### 状态（8 维，对抗上下文特征）
```
s = [
  turn_ratio,            # 当前轮次 / max_turns（归一化 0-1）
  evidence_density,      # 最近 3 轮 evidence_quotes 数 / 3（证据密度）
  answer_quality,        # 最近 3 轮规则打分均值 / 5（回答质量，规则兜底评分）
  mode_ordinal,          # 当前模式序数（normal=0 / pressure=1 / catfish=2，归一化）
  catfish_streak,        # 已连续鲶鱼轮数 / CATFISH_MAX_CONTINUE(2)
  level_mix,             # 学生画像水平（beginner/intermediate/advanced 编码）
  dimension_variance,    # 六维分数方差（越高越需要加压探测）
  cost_ratio,            # 已消耗轮次预算比例（成本感知）
]
```

### 动作（3 离散，与现有模式一一对应）
```
0 = normal     # 常规追问
1 = pressure   # 加压追问
2 = catfish    # 鲶鱼（打破僵局）
```

### 奖励（可复算，四个分量）
```
r = w1 * Δsix_dim_avg      # 训练收益：本轮六维均分相对对抗前基线提升
  + w2 * Δevidence_density # 对抗质量：证据密度提升（学生被逼出更多论据）
  - w3 * token_cost        # 成本惩罚：本轮 LLM 调用 token 归一化
  - w4 * catfish_abuse     # 纪律惩罚：连压 > CATFISH_MAX_CONTINUE 重罚（防捷径）
```
**权重初值**（可调）：w1=0.5, w2=0.3, w3=0.15, w4=0.05 ｜ 关键：w4 必须有——M3 踩过的坑是"策略学'高频动作'捷径"，鲶鱼滥用会毁掉对抗真实性

## 三、训练范式（复用 M3 已验证路径）

1. **warmup_with_rules**：先用现有规则版鲶鱼策略（CATFISH_MAX_CONTINUE=2 逻辑）做监督预热——规则是安全起点
2. **PPO 微调**：在线交互对抗环境（`CareerAdversaryEnv`：模拟学生作答 + 六维打分），GAE λ=0.95，clip 0.2
3. **3-seed 实测**：seeds 1/42/2024，对比规则版 vs MAPPO 版（奖励/证据密度/成本/鲶鱼频次分布）

## 五、验收标准

| 项 | 标准 |
|---|---|
| 正确性 | 3-seed MAPPO 奖励 ≥ 规则版；证据密度 ≥ 规则版；成本 ≤ 规则版×1.1 |
| 纪律 | 鲶鱼连压 > 2 轮发生率为 0（防捷径） |
| 降级 | mappo 异常时自动回规则版，输出标记，链路不中断 |
| 测试 | `tests/test_career_policy.py` ≥12 用例（状态特征/奖励可复算/动作映射/降级/灰度关闭零影响） |
| 落盘 | `experiments/results/career_catfish_mappo_eval_YYYYMMDD.json`（逐 seed） |
