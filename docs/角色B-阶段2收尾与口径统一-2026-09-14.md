## 2. 事实一：那条判决是「欠训练伪影」

**机制**：`experiments/eval_review_mappo.py`（角色 C 产物，`4d6b179`）第 180 行调用
`train_ppo(episodes=args.ppo_episodes, ...)` **不传 `batch_episodes`**；而 `d55387e` 起该参数
默认 48。故其默认 `--ppo-episodes 60` 只产生 **2 次**梯度更新（实测 `n_updates=[2,2,2]`）。
已入库的 `review_mappo_eval_20260914.json` 自述 `"ppo_episodes": 60`，属同一口径。

**取证**：`scripts/verify_review_stage2_wrapup.py`（B 产出，显式传 batch 并落盘 `n_updates`）。
同一脚本、同一 seeds(7/42/2026)、**唯一变量 = 更新次数**（四方案统一施加生产同源纪律护栏）：

| 预算 | n_updates | **rl** | uniform | rule | supervised | rl ≥ uniform |
|---|---|---|---|---|---|---|
| 60 ep | 2 | 6.9313 | 10.8369 | 7.7609 | 6.6349 | ❌ |
| 1200 ep | 25 | 8.1580 | 10.8369 | 7.7609 | 6.6349 | ❌ |
| 3000 ep | 63 | **11.3835** | 10.8369 | 7.7609 | 6.6349 | ✅ (+5.0%) |

`improved_deterministic` 三档均为 True；`discipline_ok` 三档均为 True。

⇒ 回报随更新次数**单调上升**，63 次时 RL 反超均匀基线。**"收益空间为 0" 不成立。**

## 3. 事实二：但 RL 的"赢"不能表述为"提升评审质量"

三条读数共同证明当前合成环境的**动作—指标解耦**：

1. **`mean_quality_gain` 四臂逐位相同（0.1737）**。`ReviewEnv.step` 里
   `self.consistency += 0.03`（机械、**与动作无关**）⇒ 该指标**按构造**不可能区分策略。
   阶段2 文档用"终态质量 66.84 / 质量增益 16.839"论证优劣，属**对不可区分指标的解读**。
2. **`precision_rate` 四臂全 1.000**。`precision = (consistency ≥ 0.5) or (action != 4)`，
   护栏下 skip 绝迹（连发 ≤1）⇒ `precision` 项（权重 0.35，第二大的分项）对动作**无判别力**，
   只是一段恒定偏置。（阶段2 文档 §3.3 第 2 条已指出该现象，本轮确认**修复后依旧存在**。）
3. **唯一动作相关的奖励通道是 `_gain(action)`**：`MATCHED 5.0 / BALANCED 3.0 / MISMATCH 1.0 / SKIP 0.0`。

⇒ RL 的优势**等价于"更常命中 `_true_best()` 档位"**，而 `_true_best()` 是环境作者写死的判据。
**这是环境内自造的最优，不构成真实教学增益，不构成对外卖点。**

## 4. 事实三：我引入的跨角色口径漂移（须 C 同步）

- `d55387e` 把 `ReviewEnv.consistency` 由固定 50.0（0–100）改为 `uniform(0.15,0.90)`（0–1，语义更正确）。
- **副作用**：`eval_review_mappo.py:111` 硬编码 `thr = 75.0 if idx == 4 else 60.0` ⇒
  精准率读数由 **0.513 → 0.000**（实测四臂全 0）——即"精准评审"这一验收维度在 C 的表里被静默清零。
  取证：用 C 原脚本在新环境上重跑（`--ppo-episodes 3000`），四臂 `precision_rate` 全为 `0.0`
  → `py-server/experiments/results/_b_wrapup_budget3000.json`。
  （注：该临时 JSON 的其余列同样受此阈值影响，**不作真值源**，仅用于坐实"静默清零"这一现象。）
- **B 侧处置**：在自己的取证脚本内改为**引用环境原生语义**（`(consistency ≥ 0.5) or (action != 4)`），
  并加**量纲哨兵** `_check_scale()`（一致性超出 `[0,1]` 即显式抛错），杜绝同类静默漂移再次发生。
- **待 C 处置**：`eval_review_mappo.py` 的阈值改为同源引用，并落盘"环境版本指纹"。**B 不擅改 C 的文件。**

## 5. 事实四：C 脚本绕过了生产纪律护栏

`eval_review_mappo.py` 的 `rule` 臂直接调 `_rule_action_idx(feats)`，**未经**生产
`decide_review_weight` 内的 `_block_skip` ⇒ 该脚本报 `discipline_ok=False`、`max_skip_streak=2`，
与攻坚令阶段3 验收项「skip 连发 ≥2 发生率为 0」直接冲突。

四方案**统一施加护栏**后（B 脚本口径）：`discipline_ok=True`，rule 连发 1、skip 率 0.072，rl 连发 0。

⇒ 该 `False` 是**脚本伪影**，不是策略违规。但"验收表由未加护栏的脚本产出"这件事本身必须修，
否则阶段3 的验收数字不可信。

## 6. 事实五：`rule` 不是生产基线

生产灰度关闭时 `decide_review_weight(use_mappo=False)` 返回**均匀权重**（idx 3），
代码里**不存在** `_rule_action_idx` 这条生产路径（它只是预热标签来源与对照臂）。
故"A ≥ rule ≥ supervised"中的 rule / supervised 均为**对照臂**；对外的"现状"只能是 uniform。

## 7. 收尾结论（B 的最终口径）

**可以讲**

- 【唯一非自造证据】角色 C 的校准环境 + 贴近真实特征空间
  （**口径**：真实特征提取管线 + 合成上下文采样；**不是**真实 trace ——
  真实 trace 复评管线 `experiments/eval_review_mappo_real.py` 已就绪但尚无真实输入）
  （`py-server/experiments/results/review_shadow_summary_20260914_164556.json`）：
  RL 影子策略 **69.896 > 固定规则 68.948（配对 t=3.08）**，"塌缩为恒定 balanced" 由 92/240 降至 9/240；
  留出集同向复现（+1.005, t=3.33）。
- 【本合成环境内】足预算下 RL 回报 **11.3835 > uniform 10.8369（+5.0%）**，纪律零违规
  （但受 §3 限制，**不可作为对外卖点**）。

**不可以讲**

- ❌ "RL 优于现状/均匀基线"当作真实结论——该优势只在 B 自己改过的合成环境里成立（§3）。
- ❌ "RL 提升评审质量"——质量指标按构造成动作无关（§3-1）。
- ❌ "RL 优于解析启发式"——符号不稳（集合 A +0.09 / B −0.357，留出集翻转）。
- ❌ 任何"真实教学增益"——需阶段 4 试点/真实 trace 数据。

**灰度**：`use_review_mappo` 维持 `False`。
