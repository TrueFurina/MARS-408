### 1.1 实现要点（对齐攻坚令 3.1/3.2/3.3）

- **状态**：12 维评审上下文（`review_state_features`），确定性可复算。
- **动作**：5 档离散权重 `REVIEW_ACTIONS = [trust_honest, trust_critic, trust_consensus, balanced, skip_review]`。
- **网络**：独立 ActorNet / CriticNet（**未改动** `engines/mappo_policy.py`，零侵入既有 648 基线）。
- **奖励**：4 分量 `gate 0.4 / precision 0.35 / cost 0.15 / discipline 0.10`。
- **学习**：`warmup_with_rules`（规则监督预热）→ `train_ppo`（CTDE + GAE + clip）。
- **协议入口**：`decide_review_weight(features, use_mappo, skip_streak, reviews_done)`；`use_mappo=False` → 均匀权重（= 现状，灰度安全）。
- **纪律硬约束**：`reviews_done < REVIEW_MIN_REVIEW(2)` 禁 skip；`skip_streak >= SKIP_STREAK_LIMIT(2)` 压回 balanced。
- **灰度**：`config.gomarl.use_review_mappo` 默认 `False`。

### 1.2 本轮修复的真实缺陷

**输入 sanitize 缺失（B 侧自查发现）**：NaN/Inf 进入线性层**不会抛异常**，会静默产出任意权重，
使"异常 → fail-open 均匀权重"的兜底形同虚设。已新增 `_features_valid()`，在
`select_action` 与 `decide_review_weight` 两层拦截，非法输入直接返回均匀权重。

## 2. 3-seed 实验结果（唯一真值源：JSON，非本报告）

配置：`seeds=[7,42,2026]`、`episodes/cell=30`、`horizon=6`、`warmup_steps=300`、`ppo_episodes=60`、
`degraded=False`（torch 2.13.0+cpu **真训**，非降级模拟）。

| 方案 | 回报(mean±std) | 质量增益 | 终态质量 | token | skip率 | 精准率 | 连发 |
|---|---|---|---|---|---|---|---|
| **uniform（=现状基线）** | **6.3627 ± 0.0702** | 16.839 | 66.839 | 5700.0 | 0.000 | 0.513 | 0 |
| rule（固定规则） | 5.3564 ± 0.0691 | 14.304 | 64.304 | 5596.1 | 0.000 | 0.513 | 0 |
| supervised（纯监督预热） | 5.4013 ± 0.0752 | 14.417 | 64.417 | 5600.0 | 0.000 | 0.513 | 0 |
| rl（warmup + PPO） | 6.0731 ± 0.1411 | 16.109 | 66.109 | 5666.7 | 0.000 | 0.513 | 0 |

**判据核对**

- `rl >= rule`：✅ True，增益 **+13.38%**
- `rl >= uniform`（现状基线）：❌ **False，−4.55%**
- `rule >= supervised`：False
- 纪律：`discipline_ok=True`，`max_skip_streak_overall=0`（skip 捷径已封死）

## 3. 根因诊断（为什么 RL 没赢过均匀基线）

### 3.1 动作分布：RL 退化为恒定动作

诊断（seed=42 策略，在 seed=999 环境跑 30 episode）：

```
RL  动作分布: {'balanced': 1.000}
规则动作分布: {'trust_honest': 0.333, 'balanced': 0.667}
```

### 3.2 决定性证据：恒定动作消融（收益上界）

`python experiments/eval_review_mappo.py --ablation --seeds 42`
→ `experiments/results/review_mappo_ablation_20260914.json`

| 恒定动作 | 回报 | 质量增益 | token | skip率 |
|---|---|---|---|---|
| 0 trust_honest | −0.0433 | 6.154 | 5400 | 0 |
| 1 trust_critic | 0.8851 | 8.413 | 6000 | 0 |
| 2 trust_consensus | 4.9113 | 14.228 | 4800 | 0 |
| **3 balanced（最优）** | **6.3784** | 16.898 | 5700 | 0 |
| 4 skip_review | **−9.6009** | −0.002 | 0 | 1.000 |

```
best_constant        : 3:balanced
best_constant_return : 6.3784294705618505
rl_return            : 6.3784294705618505   ← 与最优恒定动作逐位相同
```

**结论升级**：不是"RL 没训练好"，而是 **RL 精确收敛到了该环境下的最优策略，而最优策略恰好就是
恒定 `balanced` = 现状均匀权重**。即：**在当前合成 `ReviewEnv` 下，评审权重 MAPPO 化的理论收益空间为 0**。
调参、加训练量、换网络都无法突破这个上界——问题出在环境可分性，不在训练侧。

三条线索互相印证：

1. **skip 动作被纪律约束完全封死**（`skip_rate=0`）→ 5 动作头实际仅 4 个可用，唯一能显著省成本的自由度消失；
2. **精准率四方案完全相同（0.513）** → `precision` 奖励项对动作不敏感，环境未建模"权重点错了会怎样"；
3. **质量增益无状态可分性** → 状态噪声下条件化权重与恒定权重的期望增益无显著差异，PPO 只能收敛到先验（balanced）。

### 3.3 正面收获：纪律机制经验证有效（攻坚令风险项）

恒定 `skip_review` 策略回报 **−9.6009**（质量增益 −0.002）→ 证明"一律 skip 省 token"的捷径
**已被奖励重罚 + 纪律硬约束彻底封死**。该防线是真实生效的，不是纸面设计。
3-seed 全量 `max_skip_streak_overall = 0`、`discipline_ok = True`。

> 注：`rl > rule` 的 +13.38% 只说明"学到了一个比规则因子更稳的均衡"，**不等于 MAPPO 化对现状有增益**。
> 对外引用时必须说明对比口径，否则构成误导。

## 4. 建议（需 CTO / 用户决策，B 不擅自执行）

| 选项 | 内容 | 风险 |
|---|---|---|
| **A（保守·推荐）** | 如实报告"相对固定规则 +13.38%，未超均匀基线 −4.55%"；灰度保持 `use_review_mappo=False`；**不落盘 `models/review_weight_policy.pt` 为默认策略**（否则线上反而劣化） | 无。代价是本次 MAPPO 化暂无正向卖点 |
| B（改环境·**唯一技术出路**） | 让 precision 与动作相关、放宽 horizon 末尾 skip 纪律，重跑 | ⚠️ 属 C 的实验设计职责；且"改环境让 RL 赢"有调参造数嫌疑，须由 CTO 书面背书。**但消融证明训练侧已到上界，不换环境就永远不会有增益** |
| C（换真数据） | 用真实评审 trace 替代合成环境评估（契合大创真版"真数据"要求） | 需要真实 trace 样本，工作量最大但证据力最强 |

**B 的立场**：推荐 A。当前证据不足以支撑"评审权重 MAPPO 化提升质量"的对外宣称；
在拿到可分环境或真实 trace 之前，宁可报负结果。
