一、系统架构总览（生产流水线 · LangGraph 13 节点实测）

triage 分级路由→ coordinator 全局协调 + 教学策略决策→ diagnostician 学情诊断→ planner 任务规划→ retriever 检索优化→ generator_cluster 7 智能体生成集群→ assessor 评估反馈→ critic 批评者 + 证据门禁→ evidence_check 证据校验→ quality_gate 产物闸门→ path_planner 路径规划

🔀 Triage 分级路由（M1）

零 LLM 规则分类器，安全默认 high。寒暄/简短答疑 → low 短路快速回答，零评审、低时延；学习类请求 → high 进完整流水线 + 三评审。

🔍 三元评审校验壳（M2）

诚实 Agent 如实产出（无事实不编造）→ 共识 Agent GOMARL 证据加权合成 + 置信度 → 批评者 Agent 结构化 JSON 审阅，证据门禁拦截无证据批评。

🧠 MAPPO 教学策略层（M3/M4）

协调阶段决策 难度档位 / 讲解方式 / 评审强度；CTDE 共享 Critic，3-seed 实测正确率 0.963±0.000 与专家规则持平。

实测节点顺序（mock LLM 端到端冒烟）：triage → coordinator → diagnostician → planner → retriever → planner → retriever → generator_cluster → assessor → critic → evidence_check → quality_gate → path_planner ✅

① 诚实 Agent：7 个子智能体（Teacher/QuizMaster/MindMap/…）基于检索知识如实生成，无证据不编造。
② 共识 Agent：GOMARL 对 7 份产出证据加权合成 → consensus.status=passed，置信度 0.95。
③ 批评者 Agent：结构化 JSON 审阅（verdict + issues[point/evidence/suggestion]）。
④ 证据门禁：无证据批评（evidence=null）不触发重生成 → 记入 filtered_issues 并降级通过。
