## 二、深层问题模式（三起问题为什么会出现）

三个待办不是孤立 bug，而是同一套**模式**的三次显现。看穿模式，才能防复发。

### 模式 1：复刻代码时丢失"随机性治理"

`career_policy.py` 复刻自 `engines/mappo_policy.py`（M3 已验证模块），但**丢失了三路播种**（python/numpy/torch）：
- 原模板 434/480 行有正确 `random.seed` + `torch.manual_seed`；career 复刻漏掉
- 且 warmup 内 `rng = random.Random(seed)` **建而不用**（伪播种）
- 后果：同 seed 两次运行 L2 差异 110.70，3-seed 结论不可复算

**规律**：复刻已验证代码时，**验证性细节**（播种、断言、降级）最容易丢——因为它们不改变"功能路径"，只改变"可信度"。

### 模式 2：合成环境"基线有效性"未先验证

career 规则基线在部分特征来源下 **100% 恒定 `normal`**（详见派单一）——但这个问题直到被复查才暴露。原因：
- 训练脚本先跑通（曲线收敛），没有人先问"**规则基线在这个环境下真的会触发对抗吗**"
- 环境动力学设计精细（卡住型学生、收益递减、纪律重罚），但**规则阈值与特征分布之间的接口**无人验证
- 后果：若规则基线失效，"MAPPO 超规则"就是**在几乎失效的基线上取得的胜利**，答辩一问即穿

**规律**：实验必须先验证**基线有效性**，再谈方法增益。基线不会动，不代表基线是对的。

### 模式 3：实验结论与叙事脱节

review 线发现"解析式占满 all headroom"——这是重大发现，但 novelty 叙事（"MAPPO 在线调权超一切"）没有同步更新，若直接对外，就是新的声称>证据。

**规律**：实验改变结论时，叙事文档必须同步变更；叙事滞后 = 新的口径事故。

### 模式 3 的深层根源（CTO 判断）

三起问题共同指向一个缺口：**流程里缺少"实验基线有效性检查门"**——类比生产代码的 quality_gate，实验也需要一个 gate：跑训练前先验证（a）基线会动（b）基线有效（c）随机性可控。本令第六节给出机制建议。

## 三、派单一：career 规则基线失效（🔴 产品级，优先级最高）

### 3.1 问题现象（证据）

`docs/B-career线不可复现复查报告-2026-09-14.md`（角色 B 复查，CTO 复核代码确认）：

1. **规则基线在部分特征来源下 100% 恒定 `normal`**——escalating / catfish 从未触发
2. 同一规则版在**不同特征来源下行为不一致**（合成 env 特征能触发、真实 turns 特征可能永不触发）——这本身即"环境保真度"问题
3. 根因已在代码确认（见 3.2），**未修复，需派单**

### 3.2 根因分析（CTO 复核代码，`engines/career_policy.py`）

**根因 A：规则阈值与特征默认值不匹配（主因）**

```python
# _rule_action_idx：density >= 0.45 → 恒 return 0 (normal)
if density < 0.35: return 2 if quality < 0.45 else 1
if density < 0.45: return 1
return 0

# career_state_features：turns 无 evidence 时 density 默认 0.5
evidence_density = sum(dens)/len(dens) if dens else 0.5
```

**`0.5 ≥ 0.45` → 规则永不触发对抗**。真实特征空间（turns 提取）中，若学生回答未带结构化 evidence（或为空），密度落默认 0.5，规则死锁在 normal。

**根因 B：状态维度退化（次因）**

`career_state_features` 8 维中至少 2 维恒常数：
- `level_code`：`profile_level` 固定（默认 intermediate → 恒 0.5），合成环境不变
- `dimension_variance`：`six_scores` 缺失/稳定时走常数分支（恒值）
- 第 8 维（cost_ratio 类）在合成环境亦为常数
→ **8 维状态里约 3 维是常数**，状态空间有效维度退化，信息量不足

**根因 C：环境动力学与规则接口无对齐验证**

`CareerAdversaryEnv` 设计精细（开局 density=0.34、normal 掉密度 -0.06、cap_catfish(0.50)<cap_escalating(0.85)、token 成本 600/900/1100）——环境是"值得用"的，但**从未验证规则版在该环境下按预期触发**。

### 3.3 影响评估

| 影响 | 严重度 | 说明 |
|---|---|---|
| career "MAPPO 超规则"对比基线失真 | 🔴 | 若规则在真实特征空间死锁 normal，"超规则"只在"规则失效"意义上成立 |
| 答辩风险 | 🔴 | 评委问"规则版为什么没触发鲶鱼"→ 当场穿帮 |
| P5 试点风险 | 🟡 | 规则版是线上默认路径（use_mappo=False 时），死锁 = 真实学生得不到对抗训练 |

### 3.4 修复方案（派单给角色 B，照此执行）

1. **对齐阈值与默认值**：`career_state_features` 中 `evidence_density` 默认值改为 `0.5 → 0.3`（与"卡住型学生"开局 0.34 同量级），或 `_rule_action_idx` 增加"无证据轮"分支（n<2 时直接 normal，≥2 且无证据时 escalating）——二选一，**以不改规则语义为原则**
2. **修复状态退化**：`level_code` 加入 `profile` 实际值（若调用方有真实画像）；`dimension_variance` 无 six_scores 时用最近 3 轮密度方差代替，避免常数
3. **补环境-规则对齐测试**：新增 `tests/test_career_policy_baseline.py` ≥6 用例：
   - 合成 env 跑 100 局，规则版 escalating/catfish 触发率 > 0（≥ 10%）
   - 真实特征空间（空 turns/无 evidence）规则版不 deadlock（n≥2 后能触发）
   - 修复后重新跑 3-seed 对比，确认 mappo 超规则的结论**在修复后基线**下仍成立（或诚实报告变化）
4. **重跑对比**：修复后重跑 `train_career_mappo.py` 3-seed，落盘新 JSON，标注"修复后基线"

### 3.5 验收标准

- [ ] `tests/test_career_policy_baseline.py` 全绿
- [ ] 修复后规则版在合成 env 的触发率 ≥ 10%（不再 100% normal）
- [ ] 新 3-seed 对比 JSON 落盘，`mappo_reward_ge_rule` 结论在新基线下的真伪有诚实记录
- [ ] 全量回归不减（834 + 新用例）

## 四、派单二：novelty 叙事重构（🟡，与派单一联动）

### 4.1 旧叙事（已失效）

> "MAPPO 在线动态调三元评审权重"（相对 A-HMAD 监督学习）——**作为"超一切"的单一卖点已不成立**

### 4.2 为什么失效（证据）

判据 A 复现确认：`analytic_review_action`（解析式）在 effective 口径下**占满头寸（=oracle，capture 100%/100%/99.8%）**。
→ 在 effective 目标下，解析式就是最优解，RL 没有增量空间。若对外宣称"RL 调权超一切"，是**可证伪的假话**。

### 4.3 新叙事（三位一体，写进一切对外材料）

> **① 解析式最优**：在可解析的 effective 口径下，证明评审权重存在解析最优解（capture 100%，加噪 99.8% 稳健），并已作为生产默认（`RULE_MODE = analytic`）。
> **② RL 兜底复杂场景**：解析式失效的场景（字段缺失 / 目标非 effective / 强噪声）由 MAPPO 在线决策兜底，fail-open 降级。
> **③ career 线 RL 真实增益**：鲶鱼对抗模式在真实特征空间由 MAPPO 学习，3-seed 真训（RTX 5080）reward 全超规则版，证据密度 0.41→0.55，纪律违规 0——**这是唯一有真实增益数据的 RL 环节**（合成环境：真实特征提取管线 + 合成上下文采样，非真实 trace；真实增益待 P5 试点）。

## 六、治理建议（机制层面，防复发）

### 6.1 新增"实验基线有效性检查门"（CTO 强推）

类比生产代码 quality_gate，所有训练/对比实验**跑训练前**必须过此门：

```
[门] 基线有效性检查（新增，进验收模板）
  a) 基线会动吗？      → 规则版在目标特征空间触发率 > 0（≥10%）
  b) 基线有效吗？      → 基线在已知简单场景产生预期行为（如低密度→加压）
  c) 随机性可控吗？    → 同 seed 两次运行 L2 差异 ≈ 0（播种核验）
  任一不过 → 禁止跑对比、禁止出结论，先修基线
```

### 6.2 实验产物验收模板（进 INVALID-ARTIFACTS 同目录）

每个实验 JSON 必须含：`meta.baseline_checked` / `meta.seed_reproducible` / `meta.environment_source`（synthetic/trace/real）三项，缺一项按"不可引用"处理。

### 6.3 叙事变更纪律

实验结论改变时，**当天**同步更新对应叙事文档；滞后 >1 天即视为口径事故登记。
