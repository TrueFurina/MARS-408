## 0. 一句话结论

**在合成环境中，两侧验收目标现已全部达成**（评审 `RL ≥ 规则 ≥ 监督`；鲶鱼 `奖励/密度 ≥ 规则`、`成本 ≤ 规则×1.1`、`连压 ≤2`）。
但达成的前提是修掉 7 处真实缺陷 + 1 处 design 冲突；且**评审侧的"RL 优于规则"是仿真结论，不能外推为真实教学增益**；**鲶鱼侧的增益来自监督预热而非 PPO**（见 §4 局限）。

## 2. 修掉的缺陷（全部由真实运行复现，非推测）

| # | 位置 | 缺陷 | 证据 | 处置 |
|---|---|---|---|---|
| 1 | `ReviewEnv` | 退化为近简并：起点固定 (0.50/0.15/0.55) 且单调上升 → 轨迹只穿 2 个档位，规则仅在 1/6 步次优（可学增益上限 +0.13/步） | 轨迹 dump：规则=2.147 而理论最优≈2.28 | 改为 **每 episode 重采样上下文**（consistency U(0.15,0.90) 等宽区间），4 个档位都成为真最优 |
| 2 | `train_ppo` | **单 episode（6 步）即更新** → 优势标准化在 6 样本上做，梯度方差极大，策略崩坏 | argmax 从 `trust_honest` 漂到 `skip_review`；均值回报 2.01→1.75；`improved=False` 3/3 seed | 改 **batch 化**（攒 48 episode 再统一 GAE+更新）+ 熵系数 0.01→0.003 |
| 3 | `ReviewEnv.step` | **precision 语义错**：把"档位错配"也判为 precision=False，使错配奖励被 −0.35 抵消到 ≈0，**低于 skip 的 0.35**，奖励地形出现人为悬崖 | 逐步奖励 dump：错配 honest/critic/consensus = +0.05/+0.03/−0.01 vs balanced 次优 +1.48 | 按攻坚令 3.1 语义改为 **"放行判定是否正确"**（达标即正确；不达标只有真评审才算拦住）→ 阶梯恢复单调 2.28 > 1.48 > 0.68 > 0.35 |
| 4 | `_block_skip` | **纪律护栏差一**：`skip_streak >= SKIP_STREAK_LIMIT(2)` 才拦 → 连发 2 次**已经发生**，与验收指标"连发 ≥2 发生率为 0"直接冲突。**且与该项目自己的断言矛盾**：`test_evaluate_policy_reports_discipline_zero_violation` 断言 `max_skip_streak < SKIP_STREAK_LIMIT`（即 <2），而按原护栏可达 2 —— 该测试此前通过只因旧环境**从未**产生连续 skip，属"侥幸绿"而非护栏正确 | 代码审查 + 指标定义对照 + 断言反向推导 | 改为 `>= LIMIT - 1`（第 2 次发生前拦截），使护栏与既有断言一致；并让 `evaluate_policy` 对 **三方案统一施加**护栏（否则规则版会靠 skip 省成本而虚高，对比不公平） |
| 5 | `career_reward` | **成本项压倒收益项**：token 按 `/2000` 归一得 0.30~0.55，远超证据增益 0.05×0.3=0.015 → **奖励与教学效果反相关** | 规则版把密度 0.11→0.41 却只得 −0.0767，恒 normal 得 −0.0669 | 归一化基数改 **会话量级 8000**（文档只写"token 归一化"，未规定除数，属实现细节） |
| 6 | `CAREER_DELTA_CAP` | **增益上限倒置**：catfish 0.95 > escalating 0.62 → 密度越高鲶鱼相对优势越大（与"鲶鱼=打破僵局"定位相反） | 解析 reward 最优策略 = **50% 鲶鱼、token 1350**，直接违反"成本 ≤ 规则×1.1"（限 1050）→ 证明是 **reward 与验收约束的真实冲突，不是欠训练** | 改为 **catfish 0.50 < escalating 0.85**：鲶鱼只在低密度破僵局有效，密度一高边际收益归零且它更贵 → 自然收手 |
| 7 | `train_ppo` 默认预算 | **训练预算不足**：`episodes=400` 时 RL 回报 1.14~1.23 < 规则 1.26（表现为"RL 打不过规则"） | 超参扫描（见 §3.2） | 默认改 **episodes=3000 / batch=48**，并在 docstring 明确标注"预算是结论的决定性超参" |

## 4. 诚实边界与局限（不可省）

1. **合成环境 ≠ 真实效果。** `ReviewEnv` 里"环境用联合判据、生产规则用级联判据"这一差异是**建模假设**，不是实测结论。它使 `RL ≥ 规则` 在仿真中可复现，**不等于**真实教学场景存在同等增益。真实增益须等阶段 4（46 人试点轨迹）验证。
2. **鲶鱼侧 PPO 增益证据不足。** 实测 A(RL) 与 C(监督) 几乎相同（−0.01091 vs −0.01091；−0.01062 vs −0.01062；−0.01143 vs −0.01088），actor 权重确有更新（L2 Δ=0.993）但训练回报未改善（−0.08729 → −0.08762，`improved=False` 3/3）。**结论：鲶鱼侧"优于规则"来自监督预热策略本身偏离规则，而非 PPO 学习。** 文档验收表只要求"MAPPO 奖励 ≥ 规则"（已满足），但若要对内/对外主张"PPO 带来增益"，鲶鱼侧需补更好的环境或奖励。
3. **`skip_review` 结构占优。** 在设计奖励下，无论上下文 skip 都不是最优（matched 2.28 / balanced 次优 1.48 / 错配 0.68 均 > skip 0.35）。即 **5 动作空间实际有效 4 个**，纪律护栏属冗余保险。这是设计层面的观察，本轮未改奖励权重（文档写死）。
4. **规则版本身弱于"恒 balanced"。** 实测规则 1.2531 < balanced-always 1.8361：规则 37% 的决策选 `trust_honest`，而 honest 真正最优只占 6.3%。**这意味着验收基线 B 本身是次优基线**，建议后续在文档中补充"恒 balanced"参照。
5. **PPO 收敛仍有 seed 间差异**（评审 seed 42 的 RL 动作分布偏向 critic）。3-seed 均达标，但更大规模部署前建议扩到 5~10 seed。

## 6. 建议下一步

1. **评审侧**：把"恒 balanced"补为参照基线（它已强于规则），并复核 B 基线的合理性。
2. **鲶鱼侧**：当前 PPO 无增益 → 优先补环境（多回合/更真实的学生反应模型）或改用交叉熵预热后的策略梯度+baseline，别急着对外宣称 PPO 增益。
3. **训练预算**：把 `episodes/batch` 写入配置与报告模板，避免"预算不同 → 结论不同"的不可复算。
4. 两侧灰度开关（`gomarl.use_review_mappo` / `career.use_career_mappo`）建议**保持关闭**，待阶段 4 试点数据验证后再开。
