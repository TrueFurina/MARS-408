# experiments/ —— 实验台账四个固定文件

> 来源：REA #19「实验目录不是脚本堆，是**可被别人复跑的证据包**」。
> 本目录只放**已经产出过结果**的实验；临时探针放 `py-server/_scratch/` 或直接删掉。
> 一个实验目录 = 一个可复跑的最小闭环，缺任何一件都视为"未完成"。

## 目录结构（四件套）

```
experiments/<实验名>/
├── README.md        # ① 问题 / 假设 / 判据（人读）
├── config.json      # ② 全部可调参数（机器读，脚本只从它取参数）
├── results/         # ③ 原始产出（JSON/CSV，带时间戳，永不复用文件名）
└── conclusion.md    # ④ 结论 + 置信度 + 反例（人读，含"不成立"的部分）
```

**注意**：`experiments/results/`（根级）是历史遗留的平铺目录，新实验请按上面的
四件套建子目录，不要继续往里堆裸 JSON。

## ① README.md 必答五问

| 问题 | 反面（不合格） |
|---|---|
| 这个实验**要回答什么问题**？ | "跑一下看看" |
| **假设**是什么，什么结果算推翻它？ | 只写"预期变好" |
| 数据从哪来（真实/合成/回放）？规模多少？ | 不写数据来源 |
| 一条命令怎么复跑？跑多久？ | "见脚本注释" |
| 结论的**适用范围**到哪为止？ | 把合成环境结论当真实效果 |

## ② config.json 约定

```json
{
  "experiment": "mappo_policy_eval",
  "created": "2026-09-13",
  "data_source": "synthetic_teaching_env",
  "seeds": [1, 2, 3],
  "episodes": 100,
  "params": {"lr": 0.0003, "clip": 0.2},
  "notes": "合成环境：只证 effective 口径下的可解析最优，不作真实教学增益引用"
}
```

- **所有参数只在这一份文件里**；脚本里出现魔法数字 = 台账不完整（复跑时必然对不上）。
- `data_source` 必填，取值 `real` / `synthetic` / `replay`——它决定了结论能被引用到哪一步。

## ③ results/ 命名与冻结

- 文件名含 UTC 时间戳：`mappo_policy_eval_20260913T1420Z.json`。
- **只增不改**：重跑产生新文件，不覆盖旧文件（"上次的结果"本身就是证据）。
- 每个结果文件内嵌 `env` 指纹（Python/依赖版本、随机种子、git HEAD）——
  见 `scripts/env_snapshot.py`（MARL-ECDSA 同款原语）；缺失即视为"不可追溯"。

## ④ conclusion.md 必须写"哪里不成立"

一份只有好消息的结论等于没有结论。固定四段：

1. **结论**（一句话，带数字与口径）
2. **证据**（指向 results/ 下具体文件，不写"见实验结果"）
3. **不成立的部分**（哪个指标没动 / 哪个 seed 崩了 / 哪类样本没覆盖）
4. **下一步判据**（如果要继续，什么结果才算推进）

## 与合规口径的关系

- 合成环境结论必须带 `synthetic` 标记，**不得**出现在对外材料的"教学成效"栏。
- 任何要写进 README / 汇报 / 论文的数字，先过 `pilot_evidence_report` 取证闸
  （真实试用尚未开展时，成效类条数一律不得引用）。
- 本目录 `.gitignore` 不排除 results/：证据必须入库，否则三个月后无法复现。
