# MARS-408 软件杯演示走查清单（S4）

> 用途：录制演示视频前，按本清单确定性地走一遍系统，避免随机、避免翻车。
> 前置：运行 `start_demo.bat`（Windows）/ `start_demo.sh`（Linux），浏览器打开 http://localhost:5173。
> 演示账号：`demo` / `demo123456`（系统首次启动自动创建，已内置 seed 数据）。
> 配套旁白稿：`tools/demo_narration.md`。

## 0. 登录（固定）
- 打开 http://localhost:5173 → 登录页输入 `demo` / `demo123456`。
- 预期：进入主页（Dashboard），左侧为 8 智能体/功能导航。

## 1. 苏格拉底多智能体对话（核心卖点①）
- 进入 **Chat / 对话** 页。
- 固定输入（避免随机）：`"我是信安专业考生，请用苏格拉底式追问帮我搞懂『子网划分』，先让我说说 192.168.1.0/24 怎么分给 4 个部门。"`
- 预期：多智能体协作给出分层追问 + 即时答疑，不一次性给答案。

## 2. 实时证据溯源卡片（核心卖点②）
- 在上述对话的回答中，定位**引用/证据标记**（溯源卡片）。
- 点击展开：显示该结论对应的知识来源（章节/资料），体现 GOMARL 证据校验（抗幻觉）。
- 预期：每个关键结论可点开看到处，而非凭空生成。

## 3. 四科知识图谱关联诊断（核心卖点③）
- 进入 **知识图谱** 页，选择课程 `计算机网络`，知识点选 `子网划分` / `TCP 三次握手`。
- 预期：展示该知识点的跨科关联（如关联到 数据结构/操作系统相关概念）与掌握度诊断。
- 操作：点击关联节点，查看诊断建议（薄弱点 + 推荐资源）。

## 4. 讯飞 AI 工坊（赛题合规硬证据）
- 进入 **ResourceView / 资源页** 的「讯飞 AI 工坊」面板。
- 预期：展示已接入的 10 项讯飞能力（图片生成/图片理解/聚合搜索/智能PPT/数字人视频/文本纠错/公文校对/文本合规/星火角色模拟/智能简历）。
- 演示其一：上传一张图 → 调用**图片理解**，返回图文回答（验证多模态能力）。

## 5. 七种资源生成（个性化资源闭环）
- 在资源页选择一种资源类型，固定主题：`"计算机网络 - TCP 拥塞控制"`。
- 依次或选点演示：讲解文档 / 练习题库 / 思维导图 / 拓展阅读 / PPT 大纲 / 代码实操案例 / 审核报告。
- 预期：基于 FrugalRAG（E5+BM25）生成结构化资源，体现「个性化 + 准确性」。

## 6. 个性化学习路径（收尾）
- 进入 **学习路径** 页，查看基于学情画像生成的路径（含上面生成的资源）。
- 预期：路径按薄弱点排序，串联资源，呼应「降盲目性·串联知识·即时答疑」。

## 录制注意
- 全程用演示账号，避免暴露任何密钥/个人数据。
- 每个页面停留 3–5 秒，配合 `demo_narration.md` 旁白。
- 若 X2 通道仍 500（见 `py-server/api/llm_health.py` 诊断），系统会自动回退 DeepSeek，演示不受影响——但录制前建议先访问 `GET /api/llm/x2-health` 确认双兜底状态。
