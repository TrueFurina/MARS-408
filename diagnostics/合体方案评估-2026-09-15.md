## 三、文档未覆盖的 3 个阻塞项（本次评估最重要的增值）

### 🔴 阻塞 1 — 主工作树 125 个未提交文件
实测 `git status --porcelain` = **125 项**（**69 修改 / 49 未跟踪 / 7 删除**）。
文档 §3.1 仅一句"确保工作区干净"，现实是这批 WIP **含并行 AI 会话的在制品**（本仓库今日被多会话并发编辑）。直接 `git checkout main` 会**因 WIP 失败或丢失未提交工作**。
→ **必须先决策 WIP 归属**：提交（谁的）/ stash / 明确放弃。

### 🔴 阻塞 2 — push 凭证缺失
`origin` = HTTPS（`github.com/TrueFurina/MARS-408.git`）；凭证走 gh CLI，但 **gh 未登录**（`gh auth token` 为空）。
影响文档 §3.3（`push origin main` + `push origin --delete career-literacy`）与 §7 回滚（`push --force`）。
→ **需先 `gh auth login` 或注入 PAT**。

### 🟡 阻塞 3 — 合并基准与文档不一致
文档 §1.1 记"main 领先 2 提交"，其中 `bd4bcf5`（软件杯→火山杯改名）为**今日 18:52 才提交**。若文档成文早于此，其隐含基准 `79caaf8` 已过时；**实测 main tip = `bd4bcf5`**。合并前须 `git fetch` 复核基准。
