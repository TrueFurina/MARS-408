# 项目体检报告 — MARS-408 vs 学枢

> 生成时间：2026-09-02 ｜ 触发：用户反馈"项目感觉好拉，不如 学枢"
> 方法：两项目真实文件统计 + 后端实跑验证 + README 逐条核对。**所有数字均为本次实测，非推测。**

---

## 一、结论先行

**不是技术差距，是"叙事失焦 + 兑现缺口 + 工程卫生"三项落差。**

MARS-408 的代码量是学枢的 2–3 倍，功能面是 4 倍以上，且本次实测后端一次启动成功、真实对话 5.4 秒返回有效内容。
让人觉得"拉"的不是它跑不动，是**它讲的故事和拿出来的东西对不上**。

## 四、建议（按性价比排序）

### 1. README 叙事重写（约 1 小时，见效最快）

- 抬头改为**大创中期（Nov 2026）**定位，删除已结束的竞赛抬头
- 核心指标拆成 **「已实现 / 未实现」两栏**，未实现的标注计划时间：
  - 已实现：10 节点流水线真跑、2113 条向量、双通道 LLM 容灾、降级链、真实对话
  - 未实现：GoMARL 真训（当前为合成弱标注）、E5 向量检索（当前 BM25 降级）、Electron 打包

### 2. 根目录轻微整理（约 5 分钟，优先级已下调）

实测复核后，根目录整洁度其实**尚可**，仅剩少量可归位项：

- 4 个 log（`_backend_run.log` / `_vite_run.log` / `benchmark_run.log` / `eval_v2_run.log`）→ `archive/logs/`
- 6 个学校 .doc/.docx 附件（中期检查报告书、结题验收报告书等）→ `references/`
- 3 个散落文档/脚本（`overview.md`、`overview_jiaogai_preserved_2026-08-29.md`、`netlearn_for_crypto.md`）→ `docs/` 或 `references/`

> 只移不删，恪守"只读 + 仅追加"红线。**此项对观感改善有限，可延期。**

### 3. E5 模型补装或诚实标注（二选一）

- 补装：`models/e5-base-v2`（需联网下载 ~420MB；本沙箱实测 HuggingFace 不可达，需换网络环境）
- 或在 README 明确标注"当前检索走 BM25 降级路径"

### 4. 深度优先，别再堆页面（长期）

38 个 views 里挑 **6–8 个核心页面**，按学枢标准做到"专属查看器"级别的交互深度。
广度我们已经赢了，再堆页面只会稀释质感。

### 检索定量评测（真实 30 题 gold set，corpus=2113）

| 模式 | recall@5 | mrr@10 | groundedness |
|---|---|---|---|
| 纯 BM25 | 0.90 | 0.829 | 0.559 |
| 纯 E5(前缀) | 0.667 | 0.558 | 0.325 |
| **混合(生产)** | **0.90** | **0.822** | **0.601** |

**结论**：生产用 E5+BM25 加权混合（v=0.7/b=0.3）达到 90% 召回、最高 groundedness，**优于纯 BM25**。
此前"E5 不如 BM25"仅为孤立 E5 的假象；引擎已从"零向量空转 + BM25 降级"恢复为真实向量检索。

### 已知残留（非引擎 bug，属数据覆盖）

- `数据结构` 课程下个别查询（如"快速排序"）top 结果出现计组内容：KB 内 `ds_sort` 等条目对"快排"语义覆盖偏薄，软课程过滤在 top-30 无 `ds_*` 命中时优雅回退全局。属语料覆盖问题，不影响引擎正确性。
- Reranker 尝试加载 HF cross-encoder 失败（离线环境），已自动降级为无重排——功能无损。

### 追加修复（课程过滤跨课程误召回）
- **现象**：`数据结构` 课程下"快速排序"查询返回 `co_cpu`(计组) 内容。
- **根因**：E5 把查询语义拉向其它课程文本，相关 `ds_sort` 快排专条排在向量 top-30 之外（实测第 67–82 位，score 0.849）。原软课程过滤只在 top-30 内匹配 subject，找不到就退化全局 → 跨课程误召回。
- **修复**：`FrugalRAG` 带 course 约束时候选池扩至 150（`course_search_top_k`），课程过滤能兜住相关条目；扩池仍空才回退全局。
- **验证（生产路径）**：快速排序→`ds_sort`「快速排序最坏情况时间复杂度」；进程/线程→`os_process`、TCP→`transport`、Cache→`co_memory` 全部正确；`降级=False`，全真实 E5 向量。
- gold-set 课程对齐召回 18/30=0.600 中，多数未命中为评测粒度问题（gold 用细粒度话题 tcp/ip，KB 存粗粒度 transport/network），非检索失败。
