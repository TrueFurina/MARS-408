# MARS-408 演示日 Go / No-Go 决策清单

> 用途：演示前 30 分钟的放行裁决。技术绿 ≠ 可放行——**任何诚实性红线被越，一律 No-Go，与技术状态无关**。

## 一、评分项（G1–G7）的诚实性红线（不可越）

| 项 | 规则 | 可否过关 |
|---|---|---|
| **G1–G4 / G6** | 结构型伪装（规则能力被呈现为「AI/智能」） | ✅ 可过关，但**必须显式标注「v1 规则原型」**，不得暗示为神经网络/RL 真训 |
| **G5** | 调用链 / 推理轨迹（Trace） | ❌ **不得伪造 Trace**。若未接真实链路追踪，标注「链路未接入」而非编造步骤 |
| **G7** | 数据实证与训练声明 | ❌ **不得零数据纯自报**（须有 `collection_size>0` 的真实检索证据）；❌ **不得谎称已训练**——SFT/GRPO 为模拟/规则，非真训，须如实声明 |

> 底线原则：演示中每一处「智能」呈现，要么真实、要么带「v1 规则原型」标签、要么明确说「未接入/为模拟」。三者必居其一，禁止混淆。

## 二、Go 的硬性前置项清单（全部勾选方可放行）

- [ ] **状态绿**：`GET /api/status` 返回 `status=ok`、`vector_db` 可用、`collection_size≥2083`（至少 `>0`）、`llm_available=true`。
- [ ] **单端口托管**：`:8002` 同时提供 API 与 UI（裁判访问同一地址，无独立 Vite 端口）；`dist` 已构建并被后端挂载。
- [ ] **Worker 固化**：`guardian.bat` 与 `Dockerfile` 均已显式 `--workers 1`，且 `WEB_CONCURRENCY=1`；启动日志无 ADR-007 违规告警。
- [ ] **双 LLM 实测**：现场用真实问答验证——讯飞 X2 主通道可达、DeepSeek 兜底可达（断主验兜底一次）。
- [ ] **诚实标注就位**：所有规则型能力界面/说明含「v1 规则原型」；全链路无任何伪造 Trace；训练相关表述统一为「模拟/规则，非真训」。
- [ ] **备用机就绪**：备用机预热过、切换脚本在手、LAN 可达。
- [ ] **盯盘已知**：运维同学掌握每 5min 刷新 `/api/status` 与 `/metrics` 的节奏与阈值（见 Runbook）。

## 三、No-Go 触发条件

满足任一即 **No-Go**，立即回滚到最近一次绿状态并修复后再评：

1. 跨过任何诚实性红线（G5 伪造 Trace / G7 零数据自报或谎称训练）。
2. `collection_size=0` 或 `llm_available=false` 且 5min 内无法恢复。
3. 出现双写竞争迹象（多 worker / `WEB_CONCURRENCY>1` 被注入）。
4. UI 与 API 端口分离导致裁判端 CORS/漂移不可用。

## 四、裁决动作

- **Go**：记录放行时间、值守人、备用机 IP；进入盯盘。
- **No-Go**：停演示、按 Runbook 回滚、列明阻塞项，修复后重新走本清单。
