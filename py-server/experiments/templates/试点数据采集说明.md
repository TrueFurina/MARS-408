# 芒得很职 · 国创赛试点数据采集模板（T1-5）

> 本模板供**真实试点**采集使用，对接 `../scripts/pilot_stats.py`（试点成效统计）。
> 统计脚本内置诚信护栏：无显著差异如实输出、绝不编造 p 值、合成/演示数据不得冒充真实样本、样本不足（N<2）明确报错。本说明与之一致。

## 1. 文件清单

| 文件 | 用途 | 状态 |
|---|---|---|
| `pilot_pre.template.csv` | 前测模板（仅表头，零数据行） | 复制为 `pilot_pre.csv` 后填真实数据 |
| `pilot_post.template.csv` | 后测模板（仅表头，零数据行） | 复制为 `pilot_post.csv` 后填真实数据 |
| 本说明 | 字段定义、量表、流程、护栏 | —— |

**防误用约定**：模板文件名带 `.template.`，不会被统计脚本或 `find` 误认成真实样本。
**真实数据文件必须命名为 `pilot_pre.csv` / `pilot_post.csv`（去掉 `.template.`），且不得提交到仓库**（属个人隐私数据，按 `.gitignore` / 本地保管）。

## 2. 列字段定义

### 前测 `pilot_pre.csv`
| 列名 | 含义 | 来源 | 量纲 |
|---|---|---|---|
| `user_id` | 脱敏受试者编号 | 研究者分配 | 字符串/整数，**前后测一致**，无姓名全称 |
| `self_express` | 自评·表达逻辑 | 学生自填问卷 | 见 §4 |
| `self_stress` | 自评·抗压应变 | 学生自填问卷 | 见 §4 |
| `self_decomp` | 自评·方案拆解 | 学生自填问卷 | 见 §4 |
| `self_collab` | 自评·协作沟通 | 学生自填问卷 | 见 §4 |
| `self_tech` | 自评·技术汇报 | 学生自填问卷 | 见 §4 |
| `self_solve` | 自评·问题解决 | 学生自填问卷 | 见 §4 |
| `teacher_impression` | 前测教师印象分 | 教师对非盲样本打分 | 见 §4 |

### 后测 `pilot_post.csv`
| 列名 | 含义 | 来源 | 量纲 |
|---|---|---|---|
| `user_id` | 脱敏受试者编号 | 同前测 | 必须与前测逐行匹配 |
| `ecd_express` … `ecd_solve` | 系统评·6 维（ECD 评估输出） | **芒得很职系统**对学生产出的自动评估 | 见 §4（须与前测自评**同分制**） |
| `teacher_blind` | 教师盲评分（后测） | 教师对**脱敏**样本打分，不知前测成绩 | 见 §4 |
| `catfish_triggered` | 鲶鱼加压是否触发 | 系统日志标记 | **0 或 1**（整数） |

## 3. 六维含义（与系统 ECD 评估一致）

| 维度 key | 中文 | 说明 |
|---|---|---|
| `express` | 表达逻辑 | 表述条理、论点清晰 |
| `stress` | 抗压应变 | 压力下情绪稳定与应对 |
| `decomp` | 方案拆解 | 将复杂问题拆解为可执行步骤 |
| `collab` | 协作沟通 | 团队中的沟通与配合 |
| `tech` | 技术汇报 | 技术内容的专业呈现 |
| `solve` | 问题解决 | 定位根因并给出有效方案 |

## 4. 量表与分制约定（关键）

- **统一分制**：推荐使用 **0–10 整数分**（0=最低，10=最高）。
- **pre 与 post 必须用同一量纲**：`self_*` 与 `ecd_*` 是不同来源但要做 **ICC(2,1)** 与**配对 t 检验**，因此自评与系统评必须可比（同为 0–10）。若系统 ECD 输出是其他分制（如 0–100），请在采集前统一换算到 0–10，并在本说明末「实际分制记录」处注明。
- `teacher_impression` 与 `teacher_blind` 同样采用 0–10，与前两列量纲一致以便横向比较。
- `catfish_triggered` 仅取 `0` 或 `1`。

## 5. 采集流程

1. **前测**：试点开始时，学生自填 6 维自评问卷（`self_*`）+ 教师对非盲样本打 `teacher_impression`。
2. **干预**：受试者在芒得很职系统完成既定学习/训练周期，系统记录 ECD 6 维评估（`ecd_*`）与鲶鱼加压触发日志（`catfish_triggered`）。
3. **后测**：周期结束后，教师对**脱敏**样本盲打 `teacher_blind`；`ecd_*` 由系统导出。
4. 按 `user_id` 将前后测拼成两张 CSV，运行统计脚本。

## 6. 脱敏要求（红线）

- CSV **仅含 `user_id`**，不得出现姓名、学号全称、手机号等直接标识符。
- `user_id` 由研究者在本地方配，与任何公开材料脱钩。
- 原始带标识数据不得入库、不得进入版本控制。

## 7. 诚信护栏（与 `pilot_stats.py` 一致）

- 无显著差异时，脚本输出「未见显著差异」，**如实记录，不美化、不编造 p 值**。
- 真实样本量 **N 必须写入输出与证据页**；合成/演示数据**不得冒充真实样本**。
- 本统计仅反映前后测评分变化，**不构成「系统教会学生」的因果证据**；如需因果结论需随机对照设计。

## 8. 运行统计

```bash
cd py-server
python experiments/scripts/pilot_stats.py \
    --pre   experiments/templates/pilot_pre.csv \
    --post  experiments/templates/pilot_post.csv \
    --md    experiments/templates/pilot_stats_report.md
```

输出：① 各维配对 t 检验（系统评−自评）；② ICC(2,1)；③ 教师盲评 vs 系统评 Pearson r；④ 鲶鱼触发组 vs 未触发组抗压前后差。

## 9. 常见错误排查

| 现象 | 原因 | 处理 |
|---|---|---|
| `[字段缺失]` | 列名拼错或漏列 | 对照模板表头逐字核对；`self_*`/`ecd_*` 六个都不能少 |
| 量纲不一致导致 ICC 异常 | pre/post 或 自评/系统评分制不同 | 统一到 0–10 再入库 |
| 鲶鱼组间对比报「单一分组」 | 所有 `catfish_triggered` 同值 | 确有触发/未触发两类才可比；否则该节如实跳过 |
| N<2 无法检验 | 匹配后样本不足 | 真实扩样；切勿编造补足 |
