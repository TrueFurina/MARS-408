SAGE · 计算机 408 知识图谱骨架（BayesG 图结构来源）

用途：为 BayesG 自我图推断提供「知识点节点 + 先修边」的图结构；也是题库标签体系的骨架。
层级：科目 → 章 → 考点。节点=考点，边=先修/关联关系。

排序与流水线 排序 CPU-流水线 调度 —

跨科边是 BayesG ego-graph 的「关联边」来源，让系统在「补一个知识点」时能顺带点亮「同源跨科知识点」，这是 TuringMate 等产品已点出但未形式化的「四科联动」能力，SAGE 用图结构把它变成可计算、可测量（跨科命中率）。

4. 图结构落地要点（给实现）

  • 节点：上述「考点」为叶子节点，向上挂「章」「科目」两级父节点（便于按学科分层出题）。
  • 边：① 先修边（同科，有向，指向前置）② 关联边（跨科，无向/双向，权重=关联强度）。
  • ego-graph：以「当前题目命中的考点」为 ego 中心，取 1~2 跳邻域，作为「候选引导知识点」。
  • 聚焦掩码：BayesG 在 ego-graph 上采样「下一步该引导/出题的知识点」，稀疏性保证聚焦。
  • 冷启动：先用王道/教材章节目录 + 真题考点标签初始化图，再随学生错题数据增补边（错题共现 → 新增关联边）。
