### B3. 后端技术栈与多智能体架构（⚠️ 任务简报称"8-Agent"，代码实测为 9 节点）
- **框架**：FastAPI（:8002）+ **LangGraph**（StateGraph 编排）+ 100+ API 端点 + JWT 认证。
- **权威架构来源 `py-server/agents/graph.py`（文件头注释 + `create_agent_graph()`）明确为「9 节点 LangGraph」**：
  `coordinator → diagnostician → planner → retriever → generator_cluster → assessor → critic → evidence_check → path_planner`

- **节点职责**（来源 `py-server/agents/*.py` + `README.md` L380–392）：
  | 节点 | 文件 | 职责 |

  | coordinator 全局协调 | `coordinator.py` | 识别意图、任务路由 |
  | diagnostician 学情诊断 | `diagnostician.py` | 薄弱点诊断（弱项/推荐重点） |
