# D13: ruff 非风格潜在缺陷门禁固化（防回归）

> 续 D11（清 F401）/ D12（清 F821）之后，把已清零的非风格类潜在缺陷固化进提交期门禁，防回归。

## 1. 背景与目标

- D11 清 py-server 整树 `F401`（未使用导入）**225 处 / 113 文件**；D12 清 `F821`（未定义名）**8 处** latent 缺陷。清理后整树非风格类潜在缺陷归零。
- 但既有门禁 `scripts/pre-commit/f401_gate.py` 仅扫描 `F401`，其余已清零的码（`F811/F821/F822/F841`）仍可能随后续提交悄然回归。
- 本项把门禁的扫描集扩为**全部已清零的非风格缺陷码**，使这些缺陷"新增即拦截"，无需人工周期性复扫。

## 2. 改动（行为零改动）

**文件：`scripts/pre-commit/f401_gate.py`**

| 项 | 前 | 后 |
|----|----|----|
| 扫描规则 `SELECT` | `F401` | `F401,F811,F821,F822,F841` |
| 文档/日志前缀 | `F401 门禁` | `ruff 潜在缺陷门禁` |
| 覆盖码清单文案 | 仅列 F401 | 列出 5 码 + 修复提示 |

- **剔除 `F831`**：实测在 ruff 0.16.8 下 `F831` 为**未知规则选择器**（`Unknown rule selector ... in select`），若保留会使门禁直接报错、无法生效。已移除，避免携带无效规则导致误报失败。
- **文件名保留** `f401_gate.py`：守"不删除只追加"红线，仅扩展内容，不新增/改名脚本，避免动 `.git/hooks/pre-commit` 既有调用点（仍是 `[5/5]` 那道门禁）。
- 仅加固**提交期校验**，不触碰任何业务/运行时逻辑——行为零改动。

## 3. 验证（证据先行）

**3.1 有效码核验**——逐个 `--select` 验证本机 ruff 版本支持情况：

| 码 | 状态 |
|----|------|
| F401 / F811 / F821 / F822 / F841 | OK（有效） |
| F831 | INVALID（`Unknown rule selector`，已剔除） |

**3.2 负向测试（应拦截）**：构造探针文件含未用导入(F401)+重复赋值(F841)+未定义名(F821)，`git add -f` 后跑门禁：

```
[ruff_gate] ❌ 发现 ruff 潜在缺陷（F401/F811/F821/F822/F841），提交被拦截。
_d13_probe.py:1:8: F401 [*] `os` imported but unused
_d13_probe.py:5:5: F841 Local variable `x` is assigned to but never used
_d13_probe.py:6:12: F821 Undefined name `y_undef`
Found 3 errors.
```
→ 门禁 **exit 1**，正确列出 3 处真实缺陷（非无效规则误报）。

**3.3 正向测试（应放行）**：无暂存 py-server 文件时跑门禁：

```
[ruff_gate] 无可扫描的暂存 .py 文件，放行。
```
→ **exit 0**。

**3.4 提交期 5 门禁**：本交付物提交时，`.git/hooks/pre-commit` 依次跑密钥扫描 / 诚实口径 / 口径数字 / 结构守卫 / ruff 潜在缺陷（扩产后），全部通过。

## 4. 覆盖范围边界

- **包含**（fail-closed 提交门禁，防回归）：`F401` 未使用导入 / `F811` 未使用重定义 / `F821` 未定义名 / `F822` `__all__` 引用未定义 / `F841` 赋值未使用。
- **不包含**：风格类（`E`/`W`/`I`/`C`/`N`/...）与复杂度类——风格由独立 lint/CI 流程负责，不进 fail-closed 提交门禁，避免误伤正常迭代。
- **不回溯整树历史债务**：门禁仅扫描**已暂存**的 py-server 文件，不阻断既有未清项（当前整树已归零，故不会有历史债务触线）。
