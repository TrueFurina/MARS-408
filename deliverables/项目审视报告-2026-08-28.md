## 一、架构维度（架构师视角）

### 真实资产（已磁盘核实）
- **检索层**：`py-server/engines/frugal_rag.py` 真实 E5 嵌入（768 维）+ InMemoryVectorStore（numpy），生产可切 Milvus；含 BM25-only 降级守卫。
- **多智能体**：FastAPI + LangGraph，8-Agent（7 角色 + PathPlanner），`py-server/agents/`。
- **评测 harness（真）**：`py-server/experiments/eval_gold.py` —— 度量 **groundedness（检索命中比）/ answerable（≥0.6）**，是"知识可检索性"的诚实代理指标（非 LLM 作答准确率自评）。基线 `answerable_rate=0.533`（eval_gold.py:178）。
- **真实训练证据（真）**：`py-server/train_mixer_real.py` + `models/neural_mixer_trained.pt`；benchmark 实测 **Recall@5 +15.8% / MRR +16.0%**（合成弱标注，CPU 可跑）。这是当前唯一可仗的量化成效证据。
- **工程纪律**：44 测试文件、3 个 CI workflow、5 个复现脚本（先前已核实）。

### 架构风险
- `py-server/seed_data.py` 的 `KNOWLEDGE_GRAPH` 常量 **= 0 实体 / 0 关系**（末次赋值 line 1153；dir() 实测）。图谱模块是**空壳占位**，无真实规模数据。
- `py-server/db/graph_db.py` 运行时 7 个 JSON 合计 **5 实体 / 0 关系**（2026-08-28 实测）。图谱能力"已实现接口"但"无实质数据"。
- Redis 无 socket_timeout 的历史阻塞已修复（前期 BugFix）。

**结论**：架构层"能跑、有真评测、有真训练证据"，但**知识图谱是装饰性空壳**——任何文档若把它写成"已建成 613/1000 节点"即构成伪证。
