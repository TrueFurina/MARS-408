# 芒得很职 · 教师试点操作手册（对抗实训闭环）

> 版本：2026-10-21 ｜ 适用线上地址：https://mangdehenzhi.app.workbuddy.host/
> 本手册每一步都在真浏览器里走过（教师端全流程 E2E + 学生端 5 轮真实作答），
> 页面上能点的按钮、会出现的文字，都以实测为准，不是照文档想象的。

---

## 0. 开始前必须知道的四件事

| # | 事项 | 说明 |
|---|---|---|
| 1 | **姓名是绑定钥匙** | 学生注册时填写的姓名必须与花名册里的姓名**完全一致**。加入时按姓名匹配花名册行；对不上会按名单顺序绑定，看板上的姓名会与该生本人不符（成绩记到名单另一行名下） |
| 2 | **加入 ≠ 开练** | 学生凭任务码加入只算「已加入」，开始作答才产生「已开练」。试点首日看「已加入 N/M」判断到场情况，不要看「参与」 |
| 3 | **终评要等 1–2 分钟** | 最后一轮提交后报告在后台生成（约 10s 提交 + 60–90s 评估），页面显示「评估报告生成中」，**不要刷新或重复提交** |
| 4 | **报告来源看标签** | 报告页的「AI评估」标签表示真实大模型评分；若显示「规则评估」说明评估走了兜底，需反馈技术侧（不是用户操作问题） |

## 1. 教师登录与建班（约 2 分钟）

1. 浏览器打开 `https://mangdehenzhi.app.workbuddy.host/`，登录教师账号。
2. 地址栏访问 `/#/career/teacher`（或从导航进入「对抗实训 · 教师端」）。
3. 卡片 **1 · 建班**：输入班级名称（如「信息安全1班-实验组」）→ 点「创建」。
   - 页面提示「班级「×××」已创建」即成功。
   - 建错的**空班**（无名册、无任务）可删除；一旦导入名册或发布任务就不能删了（发生型证据保护），所以名字想好再建。

## 2. 导入花名册（约 1 分钟）

1. 在班级列表中**点选**刚建的班（变高亮）。
2. 卡片 **2 · 花名册与任务**：在文本框按「每行一条」粘贴：
   ```
   01 张三
   02 李四
   03 王五
   ```
   也可只写姓名（不写学号）。
3. 点「导入花名册」→ 提示「已导入 N 名学生到「×××」」。
4. 名单区逐行显示「学号 · 姓名」，右侧「未绑定」会在学生加入后变成「已绑定」。

> ⚠️ 姓名一致性：请让学生在注册时**按花名册上的姓名原文填写**（含空格、繁简）。
> 班级人数多时，建议提前把名单发到班级群，让大家照统一格式注册。

## 3. 发布任务、拿任务码（约 1 分钟）

1. 保持该班选中状态，在卡片 2 的任务行：
   - 选**情景**（下拉，如「项目答辩」类场景）；
   - 选**难度**（简单/中等/困难）；
   - 填**轮数**（4–12，建议首轮试点用 **5**）。
2. 点「发布任务」→ 出现「任务码：`XXXXXX`」（6 位字符）。
3. 把任务码分发给学生（群消息/投屏均可）。
4. 任务区会列出「本班任务」，显示每场任务的**已开始 / 已完成人数**，可随时「关闭任务」。

## 4. 学生侧操作（发这段给学生）

1. 打开同一链接，**注册**（用户名自定，**显示姓名务必与花名册一致**）并登录。
2. 进入「对抗实训」页（`/#/career/training`），首次进入如出现知情同意，点「同意并继续」。
3. 在「加入教师任务」框输入 6 位任务码 → 点「加入实训」。
4. 看到「教师任务已加入」即成功：
   - 显示「已按姓名匹配花名册：××」= 匹配正确；
   - 显示「花名册未按姓名匹配到你…」= 姓名不一致，**请按花名册改注册姓名后重新加入**，否则成绩会记错人。
5. 按页面提示选择情景 → 「进入对抗」→ 逐轮在输入框作答 → 点「提交作答」，共 5 轮。
6. 第 5 轮提交后页面显示「评估报告生成中（约需 1–2 分钟）」，**等待即可**，随后自动展示报告（综合分 + 六维 + 评估来源标签）。
7. 报告页下方可提交**课后简评**（1–5 星 + 一句话），教师看板会实时汇总。

## 5. 教师看板怎么看（试点中/后）

回到 `/#/career/teacher`，点班级右侧「看板」：

| 区域 | 读法 |
|---|---|
| 聚合数字 | 「已加入 3/3 ｜ 已开练 2/3 ｜ 完成 1/3 ｜ 完成率 33% ｜ 可评估 1」——到场/进度一屏看全 |
| 最弱维度 | 全班均分最低的三个维度（**相对排序，不是达标线**） |
| 全班六维均分 | 无数据的维度显示「无数据」，不编造 |
| 需关注 | 三类结构性事实：未开始 / 有会话未完成 / 完成但无可评分结果；得分相对靠后的学生 |
| 学生表 | 学号、姓名、完成/场次、best overall、六维均分；点姓名可下钻该生全部会话明细 |
| 课后简评 | 本班学生真实提交的星级与留言 |

**导出**：看板右上方「导出 CSV」（过程性考核依据，含表头与班级均分行）与「导出一页纸报告（PDF）」（新标签页打开自包含 HTML，浏览器打印/另存为 PDF 即可归档）。

## 6. 常见问题（按试点实测频度排序）

1. **学生加入了，看板「已加入」不涨？** → 加入只绑定名册行；确认班级选对了、且学生加入的是**本班**任务码（任务码与班一一对应）。
2. **看板显示别人名字已绑定？** → 该生注册姓名与花册不一致（见第 0 节第 1 条），改姓名后重新加入。
3. **报告等很久不出来？** → 正常 1–2 分钟；超过 3 分钟先看页面有无报错，再联系技术侧查 `assessment_source`。
4. **页面提示「该班级暂无测评数据」？** → 素养测评与对抗实训是两条线，实训数据在「对抗实训 · 教师端」看。
5. **能删班吗？** → 仅「无名册、无任务」的空班可删；有数据的班删不掉（保护发生型证据）。

## 7. 技术侧核对清单（教师不用管，出问题时提供给技术侧）

- 报告评估来源：报告页 `.src-tag`（AI评估=真实模型；规则评估=兜底，需排查）。
- 终评超时阈值：`ASSESS_TIMEOUT=150s`（免费档实测 64.2s，阈值留一倍余量）。
- 班级数据归属：`GET /api/career/classes` / `GET /api/career/classes/{id}/dashboard`（教师 token）。
- 名册绑定真相：`POST /api/career/task/join` 响应里的 `roster_bound` / `bound_match`（name / first_unbound）。
