### A1 DryRun
```powershell
.\scripts\deploy-oneclick.ps1 -Files api/auth.py -DryRun
```
判定：只输出「会上传 …」/「会发布 dist」/「[dry-run] 预演结束：未修改远端、未重启服务。」，**不出现「正在重启」**。
> 11-13 补丁后 `-DryRun` 在部署动作之后直接 `exit 0`，**已不再需要 `-NoRestart`**（带上也无妨）。若输出里仍出现「正在重启 mango-backend」，说明跑的是旧版脚本，立刻停止并核对文件。
> 预检阶段的 `Invoke-Ssh "echo KEY_OK"` 仍会连一次 SSH，所以 DryRun 需要免密通道可用，但**不会写远端**。

### A2 幂等单文件部署（验证正常路径）
选一个**本地与线上内容完全相同**的后端文件（例如近期未改动的 `api/auth.py`）：
```powershell
.\scripts\deploy-oneclick.ps1 -Files api/auth.py
```
逐项核对输出：
1. 「免密通道 OK」；
2. 「已上传」→ 上传 sha256 与本地一致（L116 校验）；
3. 「远端编译通过」（L118）；
4. 「已备份 … `.bak.<Stamp>`」——**记下这个 Stamp**；

因为文件内容与线上相同，**无论成功或回滚，线上状态都不变** —— 这是选幂等文件的原因。

### A3 故意触发回滚（关键，且安全）

现有脚本的回滚分支**只在 `Restart-Backend` 抛异常时进入**（L169-185）。不要为了触发它去故意弄坏服务。用探针超时来触发：

```powershell
.\scripts\deploy-oneclick.ps1 -Files api/auth.py -TimeoutSeconds 1
```

原理：服务实际已正常重启，但 `Wait-Healthy` 只有 1 秒窗口（L58-66 每 2 秒轮询一次），大概率返回 `$null` → `Restart-Backend` 抛「重启后 /api/status 未恢复 ok」→ 进入 catch → 执行回滚。

应观察到的输出：
```
开始回滚…
已回滚 /home/ubuntu/app/py-server/api/auth.py
部署失败，已回滚到部署前状态
```
随后**必须**跑一次 A0 复核 `status=ok`，确认服务确实活着。

三条约束：
- 仍用**幂等文件**，回滚前后线上字节一致；
- **不要**在同一轮里带 `-Frontend`：dist 的回滚是 `rm -rf $t && mv $bak $t`（L177），动静大且两处目录，单独用后端文件演练即可；
- 预期脚本**退出码非 0**（`throw`），这是设计内的，不要当成演练失败。

> 这一条同时验证了两件事：回滚链路真的能跑、以及「失败时会不会如实报错」。若输出里没有「开始回滚…」，说明 catch 没进，立刻停止后续部署计划并按 A4 准备人工兜底。

### A4 半部署失败：补丁后已自动回滚，但手工兜底仍须备好

11-13 补丁把后端文件段与前端 dist 段整体包进 `try/catch`，上传校验 / `py_compile` / dist 文件数校验失败现在**也会自动回滚并重启**，输出「开始回滚…」。预演时建议故意制造一次这类失败并确认回滚输出出现、随后 A0 复核仍绿：

- 用 `-Files` 指向一个**本地不存在的文件**（`Test-Path` 抛错）——此时还没改任何远端，`$backed` 为空，回滚会打印「开始回滚…」但无「已回滚 X」，这是正确的；
- 要验证「已回滚 X」必须让失败发生在**至少一个文件已备份之后**（例如传两个文件，第二个故意写错语法让远端 `py_compile` 失败）。

自动回滚依赖 SSH 通道可用；若通道本身断了脚本无能为力，所以手工还原命令仍须提前备好（用 A2 记下的 Stamp）：

```bash
# 后端单文件（在服务器上，需人工确认路径与 Stamp）
sudo -n cp -p /home/ubuntu/app/py-server/api/auth.py.bak.<Stamp> /home/ubuntu/app/py-server/api/auth.py
sudo -n systemctl restart mango-backend
curl -s -m 8 http://127.0.0.1:8002/api/status

# 前端两处 dist（若已执行到 L154 的 mv）
# /home/ubuntu/app/dist.bak.<Stamp>、/home/ubuntu/app/py-server/dist.bak.<Stamp>
```
演练判定：把命令写在纸上/值守卡背面，**不要等出事再翻脚本**。
