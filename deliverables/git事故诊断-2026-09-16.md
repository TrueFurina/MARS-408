## 六、给并发会话/用户的提醒

1. **恢复期只让一个会话碰 git**；其余会话暂停 `commit/push/stash/merge`。
2. **禁止** `git gc` / `git prune`（会灭掉仅存的可恢复素材）。
3. 对象库不完整时**禁止** `stash/merge/pull`（实测会摧毁 `refs/`、`HEAD`）。
4. 网络恢复后尽快 `git fetch origin` 并对齐远端；未 push 的历史已不可复原，需以"工作树重建提交"收口。
