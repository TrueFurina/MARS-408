# 芒得很职 · 国创赛试点 · 数据采集模板与字段规范

> 版本：v1.0 · 2026-09-30 · 配套《试点与MAPPO回测最小执行方案》T1-2/T1-4
> 用途：规定前测/后测 CSV 字段，使 T1-5 统计脚本（pilot_stats.py）可直接消费。
> 红线：仅采集学号后 4 位 + 姓名（或纯 user_id 匿名）；前后测用同一 user_id 关联，禁止用姓名直接关联。

---

## 一、匿名与关联方案（必守）

- 为每名学生分配稳定 `user_id`（如 `S01`…`S46`），贯穿前后测与系统日志。
- 姓名仅保留后 4 位 + 姓，且仅用于教师侧人工对照；统计文件里只用 `user_id`。
- 系统侧 `turn_id` 原话按 `user_id` 隔离落库，导出报告不含姓名全称。

---

## 二、前测 CSV（`pilot_pre.csv`，进系统前采集）

| 字段 | 含义 | 量纲 |
|---|---|---|
| `user_id` | 匿名学号 | 文本 |
| `self_express` | 自评·表达逻辑 | 1–5 |
| `self_stress` | 自评·抗压应变 | 1–5 |
| `self_decomp` | 自评·方案拆解 | 1–5 |
| `self_collab` | 自评·协作沟通 | 1–5 |
| `self_tech` | 自评·技术汇报 | 1–5 |
| `self_solve` | 自评·问题解决 | 1–5 |
| `teacher_impression` | 教师印象分（盲，无系统辅助） | 1–5 |

```csv
user_id,self_express,self_stress,self_decomp,self_collab,self_tech,self_solve,teacher_impression
S01,3,2,3,4,3,3,3
S02,4,3,3,3,4,3,3
```

---

## 三、后测 CSV（`pilot_post.csv`，完成对抗后采集）

| 字段 | 含义 | 量纲 |
|---|---|---|
| `user_id` | 匿名学号（与前测同源） | 文本 |
| `ecd_express`…`ecd_solve` | 系统 6 维 ECD 评分 | 1–5 |
| `teacher_blind` | 教师独立盲评（不看前测） | 1–5 |
| `report_pdf` | 导出的 6 维报告路径/哈希 | 文本 |
| `catfish_triggered` | 该生是否触发 ≥1 次鲶鱼加压 | 0/1 |

```csv
user_id,ecd_express,ecd_stress,ecd_decomp,ecd_collab,ecd_tech,ecd_solve,teacher_blind,report_pdf,catfish_triggered
S01,4,4,3,4,4,4,4,reports/S01.pdf,1
S02,4,3,4,3,4,3,3,reports/S02.pdf,0
```

---

## 四、系统侧自动落库（T1-3 配置后由工程师保障）

- 每轮对话 `turn_id` 原话 → 证据回放与抽样。
- 对抗轮数、鲶鱼加压触发轮序号 → 供 T2-2 回测与"鲶鱼触发率 vs 抗压提升"相关性分析。
- 导出 PDF 须含溯源信息（user_id + 时间戳 + 各维对应 turn_id）。

---

## 五、T1-5 统计脚本输入约定

- `pilot_stats.py` 读取 `pilot_pre.csv` + `pilot_post.csv`，按 `user_id` 内连接。
- 输出：各维配对 t 检验（p 值 + 效应量 Cohen's d）、ICC（自评 vs 系统评）、教师盲评 vs 系统评 Pearson r、鲶鱼触发组 vs 未触发组的抗压维度前后差对比。
- **无显著差异则如实输出"未见显著差异"**，绝不美化。
- 输入文件须脱敏；真实样本量 N 写入输出与证据页。

---

## 六、交付节奏

1. 你按本模板收**前测** → 发我（脱敏 CSV）。
2. 工程师完成 T1-3 后，学生跑系统 → 收**后测** → 发我。
3. 我跑 `pilot_stats.py` → 出 `deliverables/试点证据-<日期>.md`（T1-6）。
