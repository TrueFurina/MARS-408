## 一、OpenMAIC 深度画像（用户点名对象）

**OpenMAIC**（Open Multi-Agent Interactive Classroom，开放式多智能体互动课堂）——清华大学 THU-MAIC 团队开源，**当前教育 Agent 赛道社区关注度最高项目**。

| 维度 | 事实（来源：openmaic.io / openmaic.chat / 搜狐 2026-10 报道） |
|---|---|
| 定位 | 把任何主题/文档一键变成"AI 教师 + AI 助教 + AI 同学"的沉浸式互动课堂 |
| 编排 | **LangGraph** 多智能体状态机（课堂讨论 / 圆桌辩论 / Q&A 三种互动模式） |
| 生成管线 | 两阶段：大纲规划（Lesson Planner）→ 场景内容生成（Content Generator）：幻灯片+旁白、带评分标准的多难度测验、HTML 交互模拟、PBL 项目 |
| 动作引擎 | 28+ 动作类型（语音、白板绘图、聚光灯、激光笔等） |
| 深度交互 | Deep Interactive Mode：3D 可视化、过程模拟、知识小游戏、思维导图、浏览器内编程 |
| 实证 | **700+ 清华学生、两年+真实部署、10 万+学习记录、84.1% 满意度**；论文发表于 JCST 2026；自称首个登上联合国的中国 AI 教育智能体团队 |
| 社区 | 官网口径 3,700+ Stars；媒体（2026-10）报道 **30.8k Stars / GitHub Trending 日榜第一**——两口径冲突，引用前以 GitHub 实测为准 |
| 版本 | v0.1.0（2026-03-26）→ v1.0.0（2026-08-27，从"课件生成器"升级为"Agent 驱动的专业工作台"：可持续对话共创） |
| 技术/生态 | Next.js+React+TS；支持 OpenAI/Claude/Gemini/DeepSeek/Ollama；导出可编辑 .pptx / 交互 HTML / Classroom ZIP（支持内联资源离线用）；OpenClaw 集成飞书/Slack/Telegram 等 20+ 平台 |

**与芒得很职的关系**：赛道相邻（多智能体教育）但场景不同——OpenMAIC 做"**课程生产 + 课堂体验**"（内容供给侧），芒得很职做"**对抗实训 + 学情闭环 + 成效证据**"（能力评估侧）。它是开源标杆与流量高地，不是同构竞品。

## 三、对抗式软技能实训：与芒得很职**同构度最高**的四个标杆

这是本项目（对抗实训 + ECD 证据链评估）的正面战场，四个对象架构级相近：

### 1. Google Vantage（2026-05，与 NYU 联合验证）⚠️ 最重要对标
**四层解耦架构**——与芒得很职 ECD 设计高度同构，可互证合理性：
1. **场景生成**：先拿评估量表（rubric）看"什么算好/差"，**倒推**出能区分好坏的情境；
2. **角色扮演**：多 Agent 入场，其中 **Executive LLM 专职"制造麻烦"**（施压/不合理要求/情绪化），实时分析对话状态动态调整施压策略——"自适应考试引擎，确保该采集的证据都采集到"；
3. **行为提取**：另一 Agent 逐轮回看对话，只抽取行为证据（哪句在回避冲突/主动倾听/强行说服），**不打分**；
4. **评分**：评分 Agent 拿量表对照行为证据逐条打分，**每分必须指向具体对话片段**。
- 规模化数据：188 人实测；软技能测评成本压到"接近可规模化"。
- **对芒得很职的意义**：ECD"取证与评审分离、每分挂原话证据"的设计与 Vantage 逐层同构——这是**设计正确性的独立第三方佐证**，可写进对外叙事（引用需注明"公开报道，未实测"）。

### 2. EON Reality "The Tribunal"（2026-04，企业级 XR）
- Brainy Multi-Avatar Soft Skills 平台的对抗演进：**三个专家 Avatar（经济学家/心理学家/务实主义者）** 从不同框架质询学员，末 25% 进入 **Cross-Fire Phase**（三 Avatar 同时发难）；**Framework Collision Detection** 检测 Avatar 论点矛盾逼学员现场调和；20 分钟/场、按专长分级调强度、结业门槛分 + 复盘报告。
- 与芒得很职的三元评审 / 多 Agent 对抗几乎同构，差异在它走 XR 沉浸式、面向企业高管；芒得很职面向学生 + 教师班级闭环。

### 3. 面面俱到（Web 开源风格产品）
- 1v1 深度面试（HR/专业/压力三角色，AI 实时追问链，采够评分依据自动终止）+ **1v3 群面辩论**（强制不同立场触发辩论、交叉追问、三官独立评分）；简历解析；五维雷达 + 历史趋势；**语音分析检测 13 种口头禅与停顿**；离线演示模式。

### 4. AI 陪练剧场 ⚠️ 定位最接近的本国产品
- 9 关卡覆盖"求职面试→入职适应→独立工作"全周期；**六智能体**（场景导演/对手角色/陪练教练/压力挑战官/成长评委/成长档案官）；**六维能力雷达（表达力/逻辑力/应变力/协作力/执行力/复盘力）**+ 趋势追踪。
- ⚠️ 风险提示：其"六维雷达"与芒得很职的六维画像**概念撞车**——对外材料必须清晰陈述本项目六维的定义、数据来源与差异，避免"又一个六维"的同质化观感；建议竞品对比表正式收录。

### 5.（商业侧参照）牛客 AI 面试 —— 招聘侧，非训练侧
- 牛客企业版做的是**雇主侧规模化初筛**（万人级/日、AI 数字分身筛简历、2 秒级智能追问、防作弊），与芒得很职的**学生训练侧**是错位赛道，无直接冲突，但定义了行业基线。
- **市场数据（牛客 2026 春招白皮书口径，公开报道）**：企业 AI 面试应用率 **63.4%**；学生收到 AI 面试邀约比例 **70.4%**、受邀后参与率 **89.0%**；AI 相关新发校招岗位渗透率 26.41%→**37.56%**（同比 +543%）。
- **对芒得很职的意义**：这是产品叙事的"为什么现在"——AI 面试已成求职刚需，但**没有人训练学生通过它**；"招聘侧已 AI 化、求职侧训练缺位"正是对抗实训的价值锚点。

## 四、结论：差异化维持点 / 可借鉴点 / 风险点

### 差异化维持点（对外叙事可直接用）
1. **共识 + 证据链双机制在开源教育项目里没有同款**：GOMARL 多智能体共识引擎、NeuralMixer 动态权重融合——13 个开源项目全是"分工流水线"，无共识/冲突消解机制；仅 EduPlanner 有"三智能体对抗协同"的弱同源（用于教案而非评估）。
2. **行为证据链评估与 Google Vantage 同构**（取证/评分分离、逐分挂证据）——可引用为设计正确性的产业佐证。
3. **教师侧班级闭环 + 成效证据链**：开源同类仅 AgentSchool（浅）与 Plot-Ark（A2A 流水线）沾边；**没人做"取证闸 + 退出码契约"式的成效诚实机制**。
4. **实训 vs 招聘错位**：牛客等做"筛人"，本项目做"练人"——AI 面试渗透率数据支撑"求职侧训练缺位"叙事。

### 可借鉴点（按投入产出排序）
1. **Plot-Ark 的 xAPI 行为采集标准**——教师侧看板/学情采集若采 xAPI，可获得与院校现有学习分析栈的互操作卖点；
2. **OpenMAIC 的导出生态**（可编辑 .pptx / 自包含 HTML / 离线 ZIP）——F7 一页纸已有 HTML 自包含导出，可对齐"导出即可用"的产品标准；
3. **面面俱到的语音分析**（口头禅/停顿检测）——学生端 TTS/ASR 已通（讯飞），口头禅检测是低成本增强；
4. **AI 陪练剧场的关卡制**（L0-L8 全周期）——对抗实训的 4 场景可考虑关卡化包装，降低首次使用门槛；
5. **EduPlanner 的"教案质量五维自动评估"**——教师侧 AI 简评可加一层质量自评。

### 风险点
1. **六维撞车**：陪练剧场六维雷达与本项目六维画像概念重叠，对外必须给出维度定义差异；
2. **OpenMAIC 的势能差**：清华背书 + 30.8k Stars + 联合国曝光 + JCST 论文 + 700 学生两年实证——它若向"评估/实训"延伸即成正面竞品；但其 AGPL-3.0 与"内容生成"基因使短期延伸概率低；
3. **Vantage 类大厂下场**：Google 已把软技能测评成本打到可规模化——大厂若开放 API，自研评估器的差异化窗口在收窄；本项目的护城河应押在**教学闭环 + 本土院校场景 + 证据诚实机制**上。
