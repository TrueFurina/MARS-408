## 0. 一句话总纲

**结构可以包装，发生型证据不可造假；数字必须可溯源；禁语零容忍。**

- 结构型伪装（产品形态、v1 原型、演示流程）→ 可标注说明后使用。
- 发生型证据（真实 trace、真实成效、已训练模型、已上线数据）→ **不可编造、不可夸大**。
- 缺真实输入的地方 → 熔断标注，绝不补造数字。

## 3. 发生型证据 vs 结构型伪装 边界

| 类型 | 是否可包装 | 标注要求 |
|---|---|---|
| 产品 UI / 交互流程 / 演示动线 | 可（结构型伪装） | 标注"演示原型 / v1 规则原型"即可 |
| 功能模块清单 / 架构图 | 可 | 与代码实际实现一致 |
| 真实训练指标（MAPPO/RL 等） | 不可造假 | 必须附实验结果文件 + 字段路径 |
| 真实教学增益（学生成效） | 不可造假 | 必须附真实 trace 复评；无真实输入则熔断 |
| 基准对比结论 | 不可造假 | 注明对比基准、种子、环境来源 |

**红线**：合成环境得出的结论，**不得**表述为"真实教学增益"。

---

## 4. 真实增益 / 合成环境 标注规范

- 三元评审权重 MAPPO 化的结论，**仅证 effective 口径下"可解析最优"**，非真实教学增益。
- 对外出现相关结论时，必须注明：
  - 环境来源：`synthetic`（合成）或 `real`（真实 trace）
  - 若 `is_synthetic_fixture: true` / `verdict_valid: false` → **不得作为真实增益引用**。
- 真实 trace 复评管线（`experiments/eval_review_mappo_real.py`）已就绪，但**无真实输入、从未跑过**；在跑通前，任何"真实成效"数字一律熔断。

3. 标注环境来源（synthetic / real）与种子。
