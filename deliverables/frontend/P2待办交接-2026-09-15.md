## 7. 已知陷阱速查（本会话实证，接手者务必先读）

1. **Windows CRLF**：改文件必须 `newline=''`，否则 504 行文件变"全文件 diff"。
2. **模板根元素前禁写 HTML 注释**：会导致组件变 fragment，`mount()` 拿不到根元素。
3. **删 CSS 前先 grep 使用点**：`.glass-card` 等类可能同时被业务子卡片使用。
4. **ESLint 不解析 `<style>`**：要管 CSS 只能用 stylelint 或独立脚本（已用后者）。
5. **变异验证**：新增测试必须"故意改坏 → 测试红 → 恢复"，否则测试可能是摆设。
6. **并发会话**：`src/` 有别的会话同时在改，动手前做快照，提交前只 add 自己的文件。
