## 四、未来：三块拼图（决定项目从「作品」走向「产品」）

> **用户 2026-10-13 批准：三块拼图全部拓展**，已升级为项目主线（见 `plans/current.md` 主线节）。
> 实测前提（本轮已验）：项目**零代码改动**即可用真实 LLM —— `py-server/config.py:473` 的 env_map 原生支持
> `DEEPSEEK_API_KEY` / `DEEPSEEK_BASE_URL` / `DEEPSEEK_MODEL` / `LLM_PROVIDER`；本机实测 `LLM_PROVIDER=deepseek`
> 通道判定成功、真实调用返回可用内容（示例：「如果核心依赖明天不可用，你的方案还能跑吗？降级路径是什么，代价谁承担？」）。
> 通道探活：**DeepSeek 0.97s / 智谱 GLM 0.60s 可用**；DashScope·Moonshot·SiliconFlow·OpenRouter 因账号/地区不可用。
> 注意：服务器实测无 key、无 `.env` —— 上服务器跑基线前必须先配（实验按全局规则一律上服务器）。


### 拼图① 真实 LLM 接入 —— 把"演示可用"变成"真能用"
- **现状**：测试环境注入 mock LLM；生产链路的真实调用能力取决于讯飞 X2 单通道凭证（`4.0Ultra`/`max`/`pro-128k` 均返回 11200，属账号权限限制）。
- **判断**：这是**所有演示可信度的上限**。评委若现场给一个未预设的题目，质量直接暴露。
- **动作建议**：① 打通至少一条稳定商用通道（DeepSeek 已在白名单，可作主通道 + X2 兜底）；
  ② 做一次**真实 LLM 下的端到端质量基线**（同一组场景，mock 与真模型各跑一遍，记录差异）；
  ③ 把差异如实写进文档——**不粉饰**，因为这本身就是"我们知道边界在哪"的证据。
- **验收**：给定一个未预设题目，四场景对抗能跑完并产出结构合理、内容非模板化的六维报告。

### 拼图② 教师侧教学闭环 —— 从"一个人练"到"一个班用"
- **现状**：已有 teacher 角色、作业/提交、学习资源、班级相关端点（后端齐备）；前端教师端视图存在但**未形成闭环叙事**。
- **判断**：这是**产品价值最容易讲清楚的一跃**——"老师布置场景 → 学生对抗 → 系统自动评分 → 班级薄弱点报告"。
  相比继续加单用户功能，这条线对赛事的说服力高一个量级（有真实使用场景、有角色分工）。
- **动作建议**：① 先做**一条最小闭环**（1 个场景、1 个班、1 份报告），不铺开；
  ② 报告要能回答教学问题（哪类素养全班最弱、哪几个学生需要干预）；
  ③ 全流程留痕，形成可展示的"使用证据"。
- **验收**：教师账号可完成"布置→批阅→看班级报告"，且报告结论能由对抗记录反查。

### 拼图③ 成效证据链 —— 赛事最容易被追问的那一问
- **现状**：有 23 张 UI 快照、真实实验产物画廊（`/api/experiments`）、benchmark 产物；
  **没有**真实用户使用数据（这是事实，不能编）。
- **判断**：评委必问"多少人用过、效果如何"。**诚实答案是加分项而非减分项**——但要把它讲成"下一步计划 + 为什么可信"。
- **动作建议**：① 做一次**小规模真实试用**（哪怕 5–10 人、一个班），全程留痕（前后测、SUS 或简易满意度）；
  ② 数据量小就如实标"样本 N=8，属探索性"，不做显著性宣称；
  ③ 把"理论有效 → 小样本验证 → 规模化验证"的路径写清楚，展示方法论而非硬凑数字。
- **护栏**：**发生型证据不可造假**（项目硬红线）。宁可写"尚未验证"，不可写"已提升 30%"。

## 五、风险与护栏（会让前面全部白做的事）

| 风险 | 触发条件 | 护栏 |
|---|---|---|
| CI 静默变红 | 改了 `src/` 或 `py-server/` 后**忘记**跑 `verify_metrics.py`（本地 7 道钩子**不含**它，它是 CI 阻断项） | 每轮改动收尾固定跑；`--update` 由脚本重生成，禁手改表格 |
| 口径漂移回升 | 文档数字与代码真值脱钩（历史上反复发生） | 引用前跑机检；`docs/METRICS_CURRENT.md` 是唯一索引 |
| 假绿门禁 | 扫描面缺失/脚本恒 return 0 却报 PASS | 已修多处；新增门禁必须带**负向验证**（故意改坏必须报警） |
| Git 操作事故 | `git add -A`（junction 误判删除）、`stash/merge/pull/gc` | 逐文件显式 add；push 失败走 SSH；**推送判断不要用管道** |
| 演示翻车 | 现场网络/后端不可用 | 已做公开站"展示 + 本地运行说明"分流；本地一键脚本需在干净机器实测一次 |
| 冻结区误改 | 解冻前动了冻结交付物 | 冻结范围与解冻日期以你的口径为准（见第六节） |
