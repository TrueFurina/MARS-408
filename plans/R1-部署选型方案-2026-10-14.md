## 1. 背景与需求

拼图③（真实试用）取证闸 `MIN_PILOT{real_users:5, finished_sessions:10, max_bound_class:3, finished_with_task:5}`
要求系统对 5 名真实学生可访问。现状：

- 实验服务器 `172.16.222.99` 为内网 IP，**校外学生不可达**；
- 已发布站 `mangdehenzhi.app.workbuddy.host` 为纯静态，无后端，跑不了 career 链路。

**2026-10-14 用户拍板：公开主机托管前后端**。本文回答"用哪台主机、怎么部署"。

## 2. 部署负载实测依据（均来自本仓库代码，非估算）

| 项 | 值 | 出处 |
|---|---|---|
| 后端框架 | FastAPI + LangGraph 11 节点 | README / CLAUDE.md |
| 嵌入模型 | E5 437MB 本地常驻（sentence-transformers） | README_EN:83 |
| 向量库 | Milvus **可不装** → InMemoryVectorStore 自动回退 | CLAUDE.md:97 |
| 数据库 | PostgreSQL **可不装** → SQLite 自动回退 | CLAUDE.md:98 |
| 限流/熔断 | Redis 可不装 → 本地限流兜底（`_local_rate_limit`，非 fail-open 亦非 fail-closed） | `db/redis_client.py:194-225` |
| LLM | DeepSeek API（外网 HTTPS 调用，不占本机算力） | CLAUDE.md 数据层 |
| 种子数据 | 2015 chunks + 230 题（2026-10-14 实测） | `import seed_data` 实测 |
| 试用并发 | 5 学生 / 10 会话（取证闸上限） | pilot-runbook |

**结论：单机可跑，无 GPU 需求，无外部中间件硬依赖**——Milvus/PG/Redis 全部走 fallback，
试用规模（5 人）下本地兜底完全够用。这直接决定主机规格下限。

## 3. 候选方案对比

| 维度 | A. 腾讯云轻量 2C4G（推荐） | B. 境外 VPS（Vultr/Railway） | C. 内网 + VPN |
|---|---|---|---|
| 学生可达性 | ✅ 国内直连、延迟低 | ⚠️ 国内访问不稳，Railway 有冷启动 | ❌ 仅校内/VPN |
| 费用 | ~¥100-150/年（新用户），学生价更低 | $5-10/月起，按量不可控 | 0 |
| 备案 | 试用期可 IP:PORT 直连规避；正式上线需 ICP | 免备案 | 不涉 |
| 运维 | 轻（单机 + systemd + nginx） | 轻-中 | 0 |
| 数据位置 | 境内（学生评估数据合规友好） | 境外（敏感数据出境风险） | 内网 |
| 与现有生态 | ✅ 同腾讯系（WorkBuddy/企业微信） | — | — |

## 4. 决策

**选 A：腾讯云轻量应用服务器 2C4G（Lighthouse），Ubuntu 22.04。**

理由：
1. **零外部依赖栈**（§2 实测）→ 2C4G/5M 带宽对 5 人试用是 3 倍以上余量；
2. 学生评估数据留在境内，合规路径最短；
3. IP:PORT 直连即可开跑，**备案与域名不作为试用前置**；
4. 生态同源（芒得很职静态站已用 workbuddy.host，后续可平滑迁移到统一域名）。

### 4.1 部署架构（单机全栈）

```
轻量 2C4G Ubuntu 22.04（公网 IP）
├── nginx          反代 + 托管 site/ 静态产物 + gzip
│   └── /          → deploy/career-pilot/site/（vite 产物，base=/）
│   └── /api       → 127.0.0.1:8000（uvicorn）
├── py-server      uvicorn，systemd 守护（NETLEARN_ENV=development）
│   ├── 向量库      InMemoryVectorStore（不装 Milvus）
│   ├── 数据库      SQLite（不装 PG）
│   └── 限流        本地兜底（不装 Redis）
└── .env           DEEPSEEK_API_KEY 等，chmod 600，仅 systemd 用户可读
```

### 4.2 上线步骤清单

1. 建机：轻量 2C4G / Ubuntu 22.04 / 系统盘 50G SSD / 带宽 5M；
2. 安全组：仅开 22（限本机 IP）、80、8000（试用期）；先不开 443；
3. 环境：python3.11+（或复用 `deploy/career-pilot/backend/` 快照的
   `.python-version`）、`pip install -r requirements.txt`（E5/sentence-transformers/FastAPI/LangGraph）；
4. 传输：`scp deploy/career-pilot/backend/ deploy/career-pilot/site/ user@<公网IP>:~/career-pilot/`
   （.env/config.json 单独传输，不入 git，已在 .gitignore 封挡）；
5. 配置：`.env` chmod 600；确认 `NETLEARN_ENV` 不设 production（走本地限流兜底）；
6. 守护：systemd unit `career-pilot.service`（uvicorn main:app --host 127.0.0.1 --port 8000）；
7. nginx：反代 + 静态托管，`/docs` 可开可关（试用期建议关）；
8. 冒烟：本机访问 `http://<公网IP>/` → 首登诊断触发 → chat 流式 → 报告生成，全链路过一遍；
9. 取证闸开跑：按 pilot-runbook 第三节记录 MIN_PILOT 五项指标。

### 4.3 费用与周期

- 主机：~¥100-150/年（轻量新用户）；若走学生优惠通道可低至 ~¥50/年；
- 域名/备案/HTTPS：**非试用前置**，pilot 结束后再办；
- 从建机到学生可访问：预计 1 个工作日（环境安装 + 冒烟）。

### 4.4 风险与回退

| 风险 | 处置 |
|---|---|
| 5 人同时在线 + E5 重嵌入峰值内存超 4G | 向量库二进制缓存（.emb.npy）冷启动加载，勿频繁重启；峰值超限先限并发 |
| DeepSeek key 泄露（.env 上公网机） | chmod 600 + systemd EnvironmentFile；key 轮换预案 |
| IP:PORT 直连被厂商整治 | 启用 443 + 域名备案路径（pilot 数据不受影响，换入口即可） |
| SQLite 单文件并发写瓶颈（5 人无虞） | 若扩量再上 PG；SQLite 与 PG 已双通路 |
| 学生数据隐私 | 试用协议明示数据用途；pilot 结束导出/清理 |
