Core Capabilities

7 智能体，像一支专属教研团队

全局协调统筹、学情诊断把脉、资源生成落地、检索与双校验保驾护航，由路径规划 Agent 统一编排——覆盖讲解、练习、诊断、规划、评估全链路。

GLOBAL COORDINATOR

全局协调 Agent

统筹多智能体会话与任务流，分发子目标、聚合共识结果，保障协作不跑偏、不重复。

DIAGNOSTICIAN

学情诊断 Agent

分析作答与历史数据，定位薄弱知识点与认知偏差，输出可解释的学情画像。

RESOURCE GENERATION

资源生成 Agent 集群

按需生成讲解文档、练习题、代码实操、思维导图、拓展阅读等多类型资源，覆盖讲解到练习全链路。

RETRIEVER

检索优化 Agent

基于 Milvus + E5 召回权威资料，以真实依据抑制幻觉，保障回答可溯源。

EVALUATOR

评估反馈 Agent

跟踪作答表现与掌握度变化，给出形成性反馈与下一步学习建议，让进步可见。

QUALITY CHECKER

质量校验 Agent

对生成资源做事实一致性与质量抽检，拦截错误与幻觉，保障交付可靠。

PATHPLANNER

路径规划 Agent

综合各智能体信号，依目标院校与剩余时间动态编排每日学习路径并实时重排。

FrugalRAG · 真实性优先的检索增强

以「真实性优先」的检索增强为基座，结合 SFT（监督微调）与 GRPO（群组相对策略优化）与 ReAct 推理，在成本与回答质量间取得平衡，避免「看似正确」的幻觉式输出。

SFTGRPOReActRAG

GOMARL · NeuralMixer + 证据冲突消解

多智能体强化学习下的神经混合器 NeuralMixer，动态融合多路信号用于掌握度估计与路径决策；证据冲突消解机制在多方依据不一致时给出可信裁决。

Learning Path

五步闭环，越学越准

从一次学情诊断开始，路径规划、资源生成、练习反馈到证据校验，形成可持续优化的学习回路。

01

学情诊断

诊断 Agent 分析作答与历史，定位薄弱点与认知偏差。

02

路径规划

PathPlanner 综合多维信号，编排每日学习路径。

03

资源生成

讲解、习题、导图等多类资源按路径自动生成。

04

练习反馈

分层练习 + 多轮答疑，反馈回流至学情模型。

05

证据校验

GOMARL 冲突消解核验依据，确保讲解可溯源。
