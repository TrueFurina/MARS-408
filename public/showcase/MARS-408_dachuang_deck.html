Project Overview

项目概述

一句话定位

面向计算机 408 考研的个性化学习教学模式，以多维度学情建模驱动资源生成与复习路径规划。

研究背景与痛点

408 考生面临资源海量但匹配度低、复习路径不清、答疑反馈滞后——传统"经验驱动"教学难以规模化适配个体差异。

教改意义

将"教师经验驱动"升级为"数据驱动的个性化教学"，模式可推广至工科考研与本科核心课程。

数据结构 计网 计组 操作系统
Research Objectives

研究目标

多维度学情建模

融合知识点掌握度、学习行为、错题模式三维画像，量化刻画个体学情状态。

个性化教学模式

构建"路径规划 → 资源生成 → 智能答疑"闭环，替代千篇一律的标准化教学。

闭环可验证

以学习成效数据反哺教学策略，使教学模式具备可量化、可迭代的教改价值。

三者递进：先"看清学情"，再"因材施教"，最终"用数据证明有效"。

Innovation Points

创新点（教改视角）

① 多智能体协作教学

8 个教学角色 Agent 分工协作，模拟一支 AI 教研团队，覆盖诊断、规划、生成、答疑、校验全流程。

② FrugalRAG 个性化生成

依据掌握度生成"只属于你"的讲解文档、题库与思维导图，而非千篇一律的通用资料。

③ GOMARL 证据校验

多 Agent 强化学习交叉校验答案与资源，显著提升输出可信度，契合教学严谨要求。

④ 408 四科知识点级图谱

数据结构 / 计组 / OS / 计网全覆盖，支持知识点级诊断与靶向补救，落地到具体考点。
