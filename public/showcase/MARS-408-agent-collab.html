GOMARL Consensus

GOMARL 共识机制

多智能体强化学习下，NeuralMixer 动态融合多路信号用于掌握度估计；当多方依据不一致时，由 FrugalRAG 检索证据进行冲突消解裁决。

NeuralMixer · 动态融合权重

多路信号（诊断、检索证据、历史掌握度、练习表现）经神经混合器动态加权，融合为统一的掌握度估计——权重随学情实时调整。

证据冲突消解裁决

当多个 Agent 依据不一致（如诊断判「缓存命中」、检索判「指令流水线」），FrugalRAG 检索权威证据进行裁决，将冲突态转为已消解态。

1
冲突检出 CONFLICT 诊断 Agent 依据＝缓存命中策略；检索 Agent 依据＝指令流水线策略——两者不一致。
2
FrugalRAG 检索权威证据 基于 Milvus + E5 召回教材与真题原文，作为可溯源的第三方依据。
3
裁决 RESOLVED 以「指令流水线」为准，更新掌握度并标注证据来源，冲突消解。

协作追踪示例

一次提问如何被多智能体接力完成——从用户提问到路径规划收口，七步环环相扣。

01

用户提问

「TCP 拥塞控制怎么理解？」进入协作入口。

02

学情诊断

诊断 Agent 判「拥塞控制」薄弱，定位慢启动/拥塞避免。

03

检索增强

检索 Agent 召回权威教材与真题，供料可溯源。

04

资源生成集群

生成 Agent 产出讲解文档 + 时序图 + 配套练习。

05

评估反馈

评估 Agent 跟踪作答，给出形成性反馈与建议。

06

质量校验

质量 Agent 抽检事实一致性，拦截幻觉与错误。

07

路径规划 · 收口

PathPlanner 综合信号，编排下一日学习路径。

示例语境 · 408
用户问：TCP 拥塞控制？ → 诊断薄弱 → 检索 → 生成讲解 → 评估 → 校验 → 规划

结果：生成「慢启动 / 拥塞避免 / 快恢复」讲解 + 时序推导题，诊断将拥塞控制掌握度由薄弱调升至中等，路径规划排入次日重练清单。

FrugalRAG Loop

FrugalRAG 闭环

检索—生成—校验形成闭环，以「真实性优先」在成本与质量间取得平衡；SFT 监督微调、GRPO 群组相对策略优化与 ReAct 推理共同驱动。

检索—生成—校验，闭环自纠

每一轮生成都先经检索取得真实依据，再由质量校验拦截幻觉；未通过则回到检索重新供料，形成可自纠的闭环，而非「看似正确」的一次性输出。
