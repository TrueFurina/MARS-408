# MARS-408 快速启动指南

> 适用系统：Windows | 更新日期：2026-07-20

---

## 一、环境要求

| 组件 | 版本要求 | 获取方式 |
|------|---------|---------|
| Python | >= 3.12 | python.org |
| Node.js | >= 20.19 或 >= 22.12 | nodejs.org |
| Bun | 最新版 | bun.sh（`npm i -g bun`） |
| 可选：Milvus | 2.3+ | milvus.io（开发期用 InMemory 回退） |
| 可选：PostgreSQL | 14+ | postgresql.org（可关闭） |
| 可选：Redis | 7+ | redis.io（可关闭） |

## 二、快速启动（5 分钟）

### 2.1 克隆并安装依赖

```bash
# 前端依赖
cd study-help-pro
bun install

# 后端依赖
cd py-server
python -m venv .venv
.venv\Scripts\activate    # Windows
pip install -r requirements.txt   # 或
pip install fastapi uvicorn httpx numpy pydantic langgraph sentence-transformers
```

### 2.2 配置环境变量

```bash
# 复制环境变量模板
cp .env.example .env

# 编辑 .env，填入 API Key（至少填一个）
DEEPSEEK_API_KEY=sk-your-key-here
# 或
XF_APP_ID=your-app-id
XF_API_KEY=your-api-key
XF_API_PASSWORD=your-password
```

### 2.3 启动后端

```bash
cd py-server
.venv\Scripts\activate
uvicorn main:app --host 127.0.0.1 --port 8002 --reload
```

启动成功看到：
```
INFO:     Started server process [xxxx]
INFO:     Waiting for application startup.
INFO:     向量库为空，写入内置种子数据...
INFO:     向量库就绪，共 1883 个文档
INFO:     PostgreSQL 未启用（可关闭）
INFO:     Redis 未启用（可关闭）
INFO:     Application startup complete.
```

### 2.4 启动前端

```bash
# 新开一个终端
cd study-help-pro
bun dev
```

访问 http://localhost:5173

## 三、常见问题

### 3.1 端口被占用

```bash
# 查看谁占了 8002 端口
netstat -ano | findstr :8002
# 杀掉进程
taskkill /PID <PID> /F
# 或改用其他端口
uvicorn main:app --host 127.0.0.1 --port 8003 --reload
```

### 3.2 Milvus 连不上

完全正常。系统自动回退到 `InMemoryVectorStore`，所有功能不受影响。

### 3.3 PostgreSQL / Redis 连不上

完全正常。开发期可关闭。在 `config.json` 中设置：
```json
{
  "postgresql": { "enabled": false },
  "redis": { "enabled": false }
}
```

### 3.4 LLM 调用失败

三通道自动回退规则：讯飞星火 X2（第一优先级）→ DeepSeek → Qwen2.5
至少配置**一个**通道的 API Key。

### 3.5 E5 模型下载慢

项目已包含本地模型在 `py-server/models/e5-base-v2/`，无需联网下载。

### 3.6 Vite 连不上后端

前端请求默认走 proxy 到 `http://localhost:8002`。如果后端端口改了，修改 `vite.config.ts` 中的 proxy 配置。

## 四、启动验证清单

启动后执行以下检查确认系统正常：

```bash
# 1. 健康检查
curl http://localhost:8002/api/status
# 预期：{"status":"ok","vector_db":"inmemory","collection_size":1883,...}

# 2. 聊天接口
curl -X POST http://localhost:8002/api/chat/send ^
 -H "Content-Type: application/json" ^
 -d "{\"message\":\"什么是TCP三次握手？\"}"

# 3. LangGraph 多智能体
curl -X POST http://localhost:8002/api/agents/langgraph/stream ^
 -H "Content-Type: application/json" ^
 -d "{\"message\":\"学习TCP拥塞控制\"}"
```
