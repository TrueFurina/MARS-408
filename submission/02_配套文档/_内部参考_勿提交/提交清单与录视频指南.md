# MARS-408 — 软件杯提交清单与录制指南

> **端口约定（已全链路统一）**
> - 后端实际运行端口：**8002**（Windows 下 8000/8001 存在 TCP 僵尸 socket，需重启释放，故统一改用 8002）

> - 前端 Vite 默认 5173，`vite.config.ts` 中 `/api` 代理指向 `http://127.0.0.1:8002`

## 二、本地启动命令（录制定稿前验证用）

```bash
# 后端（8002）
cd py-server
.venv/Scripts/python.exe -m uvicorn main:app --host 127.0.0.1 --port 8002

# 前端（5173，代理到 8002）
npm run dev
```

> 健康检查：`curl http://127.0.0.1:8002/api/status`
> 若 8002 被占：改用 `--port 8003`，并修改 `vite.config.ts` 中 proxy target 为 `http://127.0.0.1:8003`。

## 五、故障排除

| 现象 | 处理 |
|------|------|
| 端口 8002 被占 | 重启电脑释放僵尸 socket，或改用 8003 + 修改 `vite.config.ts` proxy target |
| 前端白屏 | 确认 Vite proxy 指向 8002，后端 `/api/status` 返回 200 |
| LLM 无响应 | 检查 `.env` 中 DeepSeek / 讯飞 X2 密钥是否齐全，无 key 自动回退 |
