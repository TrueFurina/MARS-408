### 段落 2：画像构建 (0:30-1:30)

**旁白**：
"MARS-408 的第一步，是用对话了解你。"

"我是跨考，数据结构零基础，目标是 120 分"

- 薄弱点：数据结构全章

**画面**：点击画像卡片，展示"随学随新"的更新记录

### 段落 3：多智能体资源生成 (1:30-3:00)

**旁白**：
"有了画像，MARS-408 的多智能体系统开始为你工作。"

**画面**：进入 ResourceView，点击"生成资源"
画面分屏：左侧显示 Agent 协作流程图，右侧显示实时生成进度

**Agent 流水线动画**（按顺序高亮）：
```
Coordinator → Planner → 7 个 Agent 并行:
  ├─ Teacher → 讲解文档 ✅
  ├─ QuizMaster → 练习题 ✅
  ├─ MindMap → 思维导图 ✅
  ├─ Extension → 拓展阅读 ✅
  ├─ CodePractice → 代码实操 ✅
  ├─ PPTOutline → PPT 大纲 ✅
  └─ VideoScript → 视频脚本 ✅
```

**旁白**：
"7 个专业 Agent 并行工作，从讲解文档到视频脚本，覆盖所有学习场景。"

**画面**：快速展示生成的资源效果：
1. 讲解文档：Markdown 渲染，带知识点高亮
2. 练习题：选择题 + 填空题，带难度标注
3. 思维导图：Mermaid 渲染，逐步展开动画
4. 代码实操：代码块 + 运行结果

**画面**：底部弹出 GOMARL 共识结果卡片
"四角色交叉验证 ★★★★☆ 可信度 4.2/5"

### 段落 7：技术亮点 (5:00-6:30)

**旁白**：
"支撑这一切的，是 MARS-408 的三项核心技术。"

**旁白**：

```
检索链路显著压缩无效召回（具体成本 / 准确率增益正在 Track B 稳定 GPU 真训中量化评估，不预填未测数字）
```

**旁白**：
"FrugalRAG 轻量化检索——通过 E5 嵌入 + 阈值过滤 + RL 停止决策，显著压缩无效检索；具体成本与准确率增益正在 Track B 真训中量化评估，绝不预填未测数字。"
