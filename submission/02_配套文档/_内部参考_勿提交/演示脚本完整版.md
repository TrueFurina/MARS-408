# MARS-408 — 演示脚本（完整版 / 10 场景录制脚本）

> **录制前准备**
> 1. 后端启动：`cd py-server && .venv/Scripts/python.exe -m uvicorn main:app --host 127.0.0.1 --port 8002`
>    - 若 8002 被占（Windows 僵尸 socket），改用 `--port 8003`，并修改 `vite.config.ts` proxy target
> 2. 前端启动：`npm run dev`（默认 5173 端口）
> 3. 浏览器打开 `http://localhost:5173`
> 4. 确认 LLM 可用：讯飞星火 X2（主通道）或 DeepSeek（降级通道）

> **录制建议**：每个场景单独录制片段，后期剪辑拼接；旁白与画面同步，单场景时长见各节标注。

## 场景 1. 对话式画像构建（50 秒）

**操作**：首次进入自动跳转 `/profile/build`，AI 发开场白。

**演示对话**（输入以下 3 句，模拟真实学生）：
1. 输入：「我学过一点计算机网络，主要是应用层，TCP 三次握手不太懂，数据结构也比较弱」
2. 输入：「我是视觉型学习者，喜欢看图和做实验，目标是考研 408」
3. 输入：「我对网络安全比较感兴趣，每天能学 4 小时」

**讲解要点**：
- AI 一次只问 1-2 个问题，自然推进
- 收集到足够维度后，输出结构化画像 JSON
- 画像写入 localStorage，自动跳转主页
- **强调**：8 维度全覆盖（知识基础/学习风格/目标/薄弱点/进度/兴趣方向/学习时长/偏好难度），超额完成赛题 ≥6 维度要求
- 右上角点击「学生画像」图标，展示 8 维度雷达图

**画面**：画像完成后跳转主页，右上角「学生画像」面板可见 8 维度雷达图。

## 场景 2. 多智能体资源生成（60 秒）★重点

**操作**：点击侧边栏「Agent协作」→ 进入 `/resource`。

**演示**：
- 输入知识点：「TCP 三次握手」
- 难度选择：进阶
- 点击「生成资源」

**讲解要点**（指着流水线进度条）：
- **SSE 流式进度追踪**：顶部真实百分比进度条，逐 Agent 推送，避免白屏等待（赛题非功能 4）
- **LangGraph 10 节点 StateGraph 协同**：
  - 协调 Agent → 诊断 Agent → 规划 Agent → 检索 Agent → 生成集群(4 子 Agent) → 评估 Agent → 审阅 Agent → 证据检测 Agent → 质量闸门 Agent → 路径规划 Agent
  - 10 节点 StateGraph，含 Quality Gate 三向路由（PASS/FIX/REJECT）
- **4 子 Agent 并行生成**：教学 Agent（讲解文档）+ 出题 Agent（练习题库）+ 媒体 Agent（思维导图）+ 拓展 Agent（拓展阅读/PPT大纲/代码实操案例）
- 切换 tab 查看不同资源：讲解文档 / 思维导图 / 练习题 / 审核报告
- **审核报告**（第 7 种资源类型）：Critic Agent 事实核查 + 敏感词过滤 + 知识错误检测（防幻觉）
- **强调**：7 种资源类型（讲解文档/练习题库/思维导图/拓展阅读/PPT大纲/代码实操案例/审核报告）≥ 赛题 5 种要求

**画面**：流水线完成，4 种资源 + 审核报告展示。

## 场景 3. 算法引擎可视化（40 秒）★亮点

**操作**：点击侧边栏「算法引擎」→ 进入 `/engine`。

**讲解要点**：
- **FrugalRAG 检索引擎**：输入查询，展示检索过程（E5 嵌入 → 向量检索 → BM25 融合 → 阈值过滤 → 个性化重排序）

- **教学规则引擎**：展示 610 条教学规则 + 4 课程规则 + 10 Agent 适配
- **强调**：这是系统的核心技术差异化 — FrugalRAG 节俭检索 + GOMARL 共识投票 + 教学规则约束

**画面**：引擎面板展示检索状态、Agent 协同流、个性化对比。

## 场景 5. 答题闭环 — 学习效果评估（50 秒）★重点

**操作**：点击侧边栏「智能出题」→ 进入 `/practice`。

**演示**：
- 科目选「计算机网络」，章节选「传输层」，难度「中等」
- 点击「生成题目」
- 作答 3-5 题（故意答错 1-2 题，如拥塞控制相关）
- 点击「提交并更新画像」

**讲解要点**（指着反馈面板）：
- 显示本次正确率、各章节正确率
- **强调闭环**：后端调用 LLM 分析答题表现，动态更新 8 维度画像
  - 答错的章节 → 追加到 weak_points
  - 正确率高 → knowledge_base 升级
  - progress / interest_area / study_time 自适应更新
- 打开右上角「学生画像」面板，可见 weak_points 已变化
- **强调**：赛题「学习效果评估」的核心闭环 — 答题 → 画像更新 → 资源推送自适应

**画面**：答题反馈面板 + 画像面板更新。

## 录制备选问答

| 可能被问 | 回答要点 |
|---|---|
| 为什么选 408 考研？ | 差异化定位（多数选单科），四科全覆盖，知识点 DAG 支撑路径规划 |
| 8 维度画像怎么收集？ | 对话式自然收集，3-5 轮对话覆盖 8 维度，答题动态回写更新 |
| 如何防幻觉？ | Critic Agent 事实核查 + GOMARL 一致性校验 + RAG 教材约束 + 敏感词过滤 |
| FrugalRAG 的"节俭"体现在哪？ | SFT 策略训练让模型学会"何时检索"，减少不必要的 RAG 调用，降低成本 |
| GOMARL 共识怎么工作？ | NeuralMixer 动态加权各 Agent 输出 + 证据冲突消解（20 类矛盾对检测）|
| 知识库怎么构建？ | 408 四科教材 PDF → 语义分块(800字) → E5 嵌入(768维) → InMemoryVectorStore(Milvus 抽象层) |
| 多智能体如何协作？ | LangGraph StateGraph 10 节点 DAG：协调→诊断→规划→检索→生成集群→评估→审阅→证据检测→质量闸门→路径规划，含 Quality Gate 三向路由（PASS/FIX/REJECT）|
| 三通道 LLM 怎么切换？ | 讯飞星火 X2 优先 → DeepSeek 降级 → Qwen 备用，auto 模式自动路由 |
