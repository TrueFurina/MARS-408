# 408 考研用户痛点挖掘报告（公开社区，2026-08-29）

> 目的：为大创中期「真版」产品方向提供**真实用户需求证据**，驱动后续迭代优先级。
> 方法：联网检索公开社区（新东方考研、启航考研、搜狐、CSDN、知乎镜像站、玩转408/码虫/研芝士等刷题产品公开页面），提取考生自述痛点与竞品功能，按出现频率与共鸣度排序。
> 诚信声明：以下痛点均来自公开网络资料，附来源 URL；未编造数字，竞品功能以产品公开宣传页为准。与本项目 Gold Q&A 评测结论（计网为最弱科目）相互印证。

## 1. 痛点排名（按共鸣度 / 影响面）

### P0 — 知识体量大、四科强关联、前学后忘（遗忘）
- **现象**：408 四门课教材合计 2000+ 页，知识点零散且跨科关联（虚拟内存横跨 OS+计组+数据结构）；考生普遍"学完后面忘了前面"。
- **证据**：
  - 新东方：408 历年全国平均分仅 **60–80/150**，覆盖面广、学科交叉是核心难点。[kaoyan.xdf.cn/202507/14658429.html]
  - icode.best：强调按**艾宾浩斯记忆曲线（1/2/4/7/15 天）**滚动复盘，"人的记忆有遗忘规律，短期记忆必须不断重复"。[icode.best/i/68798657146727]
  - 上岸经验：邓海青"反复回顾、避免学了后面忘了前面"，三轮复盘。[sohu.com/a/1021230806_99899717]
- **与本项目印证**：Gold 评测中**计算机网络 groundedness 最低（0.362）**，正对应"零散易忘 / 近重复 chunk 挤占"问题，已在 `_boilerplate_factor` 修复中针对性处理。

### P0 — 只刷题不复盘、错题不归因、同类反复错
- **现象**：买真题就刷、对完答案放一边；错题"看了答案以为懂了"，换马甲仍错；不知道"为什么错"。
- **证据**：
  - 启航："错一题比刷一百题更有价值"——要按 A类(知识遗忘)/B类(思路偏差)/C类(计算失误) 归因。[jixun.iqihang.com/info/zykzd/jsj/2026753233.html]
  - icode.best："题错了以后，千万不要看懂答案就完了……把答案关掉从头推一遍"，定位"理解不够深入的地方"。[icode.best/i/68798657146727]
  - 核鲸：准确归因是有效复盘前提，按科目+模块分类错题集。[hejing001.com/sys-nd/30818.html]
  - **竞品对标**：玩转408 错题本提供"智能归因（知识盲区/审题失误/思路偏差/计算失误）+ 错误类型分布画像 + 随机组卷 + 错题趋势"，直接回应此痛点。[微信小程序「玩转408」公开宣传]

### P1 — "伪勤奋"：只看网课不动手
- **现象**：大量时间看视频、记笔记，一到做题就卡壳——PV 操作写不出、代码题没思路。
- **证据**：
  - 启航："这是典型的伪勤奋。看视频是被动输入，做题才是主动输出，408 考的是应用能力。"[jixun.iqihang.com/info/zykzd/jsj/2026753228.html]
  - 新东方跨考提醒："动手写代码，光看不练不行，建议每天手写 2-3 道算法题。"[xdf.cn/274/202605/15213793.html]

### P1 — 死记硬背、忽视知识关联，综合大题不会
- **现象**：机械背 PV 模板却不会分析生产者-消费者变体；记了 Cache 映射却解释不清对性能影响；一道大题跨计组+OS 联合（虚拟内存+Cache 一致性）无从下手。
- **证据**：
  - 启航"陷阱三"：408 越来越强调跨学科综合，需构建知识网络。[jixun.iqihang.com/info/zykzd/jsj/2026753228.html]
  - 启航真题复盘："文件系统大题可能同时涉及 OS 存储管理 + 计组磁盘调度 + 数据结构树形结构，三科一题串完。"[jixun.iqihang.com/info/zykzd/jsj/2026753233.html]

### P1 — 相近概念 / 协议易混淆（计网最突出）
- **现象**：SR vs GBN、协议 vs 接口 vs 服务、OSI vs TCP/IP 等选择题高频设陷阱；分层协议数量多、细节碎。
- **证据**：
  - CSDN：SR/GBN 窗口公式（GBN: W_T≤2^n-1；SR: W_T+W_R≤2^n）常被互换设陷阱；"实际速率≠信道带宽，易漏乘信道利用率"。[blog.csdn.net/2301_82049134/article/details/163566237]
  - CSDN/Socratopia：协议(水平/对等实体) vs 服务(垂直/下层对上层) vs 接口 是 408 最爱陷阱之一。[blog.csdn.net/lxd050925/article/details/163333741] [socratopia.app/library/kaoyan-cs-network-zh/chapter-3]

### P2 — 时间分配失衡（408 vs 数学）
- **现象**：数学(数一/数二)需大量刷题保持手感，408 同样耗时，易挤压；有考生数二 144 但 408 仅 104。
- **证据**：新东方案例"数二144分，但408仅104分，因时间分配失衡"。[kaoyan.xdf.cn/202507/14658429.html]

### P2 — 跨考 / 零基础从零搭建，C 语言底座缺失
- **现象**：非科班跨考需先补 C（指针/结构体），否则数据结构算法题看不懂程序逻辑；全程时间成本极高（建议 8–10 个月）。
- **证据**：新东方/启航多文一致："跨考先用 2–3 周补齐 C 语言基础"；"数据结构中的算法题需要用代码实现"。[kaoyan.xdf.cn/202607/15274418.html] [kaoyan.xdf.cn/202606/15247761.html]

### P2 — 缺乏个性化路径与薄弱点自动定位
- **现象**：考生渴望"系统自动找到薄弱点、按水平出题、题越做越少"，而非盲目题海。
- **证据**：
  - 知能行（数学）：AI 算法扫描薄弱点、自动衔接进度，"题应越做越少"。[hei360.com/wenda/1399844.html]
  - 码虫/研芝士/玩转408：均主打"登录后系统自动生成个性化刷题方案 / 定位盲区"。[baobeiy.com/azsoft/52096.html] [hei360.com/wenda/1401633.html]

## 2. 竞品功能映射（用户已被教育出的预期）

| 竞品公开功能 | 对应痛点 | NetLearn 现状 |
|---|---|---|
| 玩转408：AI 深度解析（逐题拆解/考点溯源/思路引导/知识点总结） | 不复盘、不会推导 | ✅ FrugalRAG 检索溯源 + LLM 可承载思路引导（待 `eval_llm.py` 验证） |
| 玩转408：知识点思维导图（掌握度可视化、红色雷区、跨章关联） | 遗忘、知识关联 | ✅ 知识图谱 + mastery 热力图（DashboardView） |
| 玩转408：错题本（智能归因+错误画像+随机组卷+趋势） | 错题不复盘 | ⚠️ 已有手动 `error_type` 单标签，**缺 LLM 自动归因 + 错误分布画像** |
| 玩转408：实时排行榜 | 孤独感（非核心学习） | ➖ 暂不做（非学习主线，符合"砍展示"策略） |
| 码虫/研芝士：个性化刷题方案、真题模拟、学习统计 | 缺个性化路径 | ✅ GOMARL 路径规划 + 每日计划（需真实训练证据支撑） |
| 知能行：薄弱点扫描、题越做越少 | 盲目题海 | ✅ GOMARL 个性化（方向一致，待量化验证） |

**结论**：用户对"AI 解析 + 掌握度可视化 + 错题归因 + 个性化路径"已形成稳定预期；NetLearn 的差异化应落在**多智能体个性化路径规划(GOMARL) + 可检索溯源(FrugalRAG) + 408 四科专精**，而非做成又一个通用刷题 App。

## 3. 产品方向建议（大创真版，落地可行、不夸大）

1. **错题智能归因（高价值、可落地）**
   - 现状：错题本仅支持手动 `error_type`（默认 concept）。
   - 建议：基于 LLM 对每道错题自动判定 知识盲区 / 审题失误 / 思路偏差 / 计算失误，生成**错误类型分布画像**（对标玩转408），驱动针对性重练。复用现有 `db/llm_provider` auto 通道。

2. **遗忘曲线驱动的自动复盘排程**
   - 将艾宾浩斯 1/2/4/7/15 天滚动纳入「每日计划」引擎，对未掌握知识点自动重排复习，而非仅一次性推题。

3. **思路引导式解析（不直接喂答案）**
   - 解析分"考点定位 → 思路引导 → 自推提示 → 完整解法"四段，呼应社区"关掉答案从头推"的高频诉求；避免直接暴露答案导致假懂。

4. **计网易混淆概念专项辨析模块**
   - 针对最弱科目（Gold 评测 CN groundedness 最低），构建 SR/GBN、协议/接口/服务、OSI/TCP-IP 等**辨析卡 + 变体题**，正面攻坚。

5. **跨考底座前置检测**
   - 新用户入门做 C 语言 / 四科基础诊断，跨考者先推 C 语言前置 mini 路径，再进四科。

6. **（不做）社交排行榜**
   - 与"砍展示、聚焦真实解题"策略一致，不投入。
